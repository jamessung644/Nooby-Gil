# SCENIC · Pleos Android 시제품

현재 앱은 **발견 → AI 코스 또는 목적지 경로 비교 → 순정 내비 요청 → 맛집·주차 → 개인 영상 리캡**으로 이어진다. 공개 사진 기반 자동 기록·리캡은 별도 샘플 체험이다. Android Studio에서 이 `android` 폴더를 열고 실행 구성 `app`, 기기 `Pleos Connect v2.1.0`을 선택해 Run을 누른다. 전체 기능과 현재 검증은 [프로젝트 안내](../README.md), Windows 실행은 [Windows 실행 안내](../WINDOWS-실행안내.txt)를 참고한다.

## 현재 구현

- **경로**에서 Kakao Local로 장소를 검색해 목적지 한 곳을 선택한다. 초기 해운대해수욕장은 변경 가능한 공개 예시다.
- 출발지는 **현재 위치 사용**, **부산역 · 시연 출발지**, **서울시청 · 시연 출발지**를 구분한다. GPS 실패를 임의의 도시로 대체하지 않는다. 공개 시연 좌표는 실제 GPS를 바꾸지 않는다. 음식점·주차장으로 목적지를 바꾸어도 선택한 출발지와 여정 맥락을 유지한다.
- 0~120분의 허용 추가 시간과 모든 풍경 또는 바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시 풍경 조건으로 같은 목적지의 도로 대안을 비교한다. 빠른 길은 Kakao 시간 우선 옵션이며, 풍경 길은 준비된 TourAPI 출처 장소 중 한 곳 인근을 통과하도록 도로를 조회한다.
- 목적지 경로 비교의 추가 시간은 빠른 길 대비 이동 시간이다. 이 모드에서는 관광지 체류나 출발지 복귀 시간을 더하지 않는다. 풍경 길이 없거나 조건을 충족하지 못하면 빠른 길만 표시하고 이유를 안내한다.
- **발견 → AI 코스 찾기**는 별도의 전체 시간 예산을 사용한다. 장소별 체류는 0·15·30분이며 복귀를 선택하면 실제 복귀 도로 시간을 포함한다. 최초 기본값은 90분·복귀 켜짐·체류 0분이다. TourAPI 후보에서 복귀 2곳 또는 편도 2~3곳을 조합하고 Kakao 도로 시간으로 검증한다. 준비된 오프라인 코스는 별도 추정치다.
- Kakao 배경 지도에 출발지·목적지·풍경 경유 지점과 조회된 도로를 표시한다. **안내 시연 시작**은 실제 주행과 분리된 단계 시연이며 실시간 길 안내가 아니다.
- **빌트인 캠 촬영**은 포함된 공개 라이선스 풍경 사진으로 촬영·저장을 체험한다. **공유 미리보기에 표시**는 기기 안에서만 보이는 설정이다. 실제 차량 카메라·영상 녹화·다른 사용자에게 전송하는 기능은 없다.
- **풍경 기록**은 선택 경로에 연결한 샘플 장면을 기기 안에 보관한다. 사진은 공유 예시이며 실제 운전자의 촬영 기록이나 선택한 도로의 실제 주행 시야가 아니다.
- **사진 근거·내 관찰 보기**에서 공개 사진의 출처와 미확인 항목을 확인한다. 사용자가 직접 관찰한 구간·날짜·방향을 기록할 수 있지만 이는 사용자 기록이며 서비스의 현장 검증이 아니다.
- **내 영상으로 리캡 만들기**에서 실제 영상 최대 6개의 1~8초 구간을 선택해 360×640·12fps 세로 MP4를 만든다. 선택 구간 합계에 안내 3초를 더하고 합성 음악·메모를 넣는다. 원본 소리는 제외하며 원본을 변경하거나 업로드하지 않는다. 공개 사진 리캡은 별도 모드다.
- **맛집·주차**는 여정의 방문 장소 주변을 검색한다. 직접 방문·전화·장소 정보로 확인한 주차 내용에 출처와 날짜를 남긴다. 30일 이후에는 재확인 표시를 하며 리뷰 자동 분석·실시간 빈자리·실제 도보 경로는 제공하지 않는다.
- **순정 내비로 안내**는 공식 Pleos NaviHelper 3.0.5로 목적지와 최대 2개 경유지를 요청한다. 출발지는 차량 현재 위치이며 순정 내비가 경로를 재계산한다. SCENIC의 Kakao 경로선·시간과 다를 수 있다. 필요한 서비스·권한·차량 위치와 실제 요청 결과는 [순정 내비 연결](../docs/NATIVE_NAVIGATION.md)을 참고한다.
- **음악**에서 OpenAI가 경로 제목·풍경·시간으로 공개 플레이리스트 하나를 고른다. **노래 재생**은 내부 공식 웹 화면을 연다. **작게 보기**로 같은 WebView를 작은 창으로 유지하며 경로를 조작하고, **크게 보기**로 복원한다. **재생 종료**만 명시적으로 플레이어를 닫는다. **외부 앱에서 열기**는 같은 목록을 공식 앱·브라우저로 연결한다. 추천만으로 재생하지 않으며 자동 재생·내부 로그인은 지원하지 않는다. 작은 창은 SCENIC 안에서만 유지되며 앱 백그라운드·차량 제한 시 종료한다.

보조 웹은 기존 탐색 시연이며 Android의 모든 최신 기능을 제공하지 않는다.

## 서버 준비

프로젝트 루트에서 Node.js 22 이상으로 `npm start`를 실행한다. 목적지 검색·경로 비교에는 `KAKAO_REST_API_KEY`, 배경 지도에는 별도 `KAKAO_MAP_JS_KEY`·Maps 활성화·도메인 등록이 필요하다. 음악 추천에는 `OPENAI_API_KEY`를 사용한다. 현재 풍경 후보는 준비된 카탈로그에서 읽으므로 단일 목적지 경로 비교에 TourAPI 키나 OpenAI 키는 필요하지 않다.

기존 `.env`를 유지하며 키는 서버에만 설정한다. 앱·소스·APK·배포 압축에 비공개 키를 넣지 않는다. **설정 → API 서버 연결**에는 `http://10.0.2.2:4173`처럼 서버 기본 주소만 입력한다. 키나 서버 코드를 바꾸면 기존 서버를 종료하고 `npm start`로 다시 실행한다. 새 APK 설치가 서버 재시작을 대신하지 않는다. API·네트워크 준비는 [API 설정](../docs/API_SETUP.md)을 참고한다.

## 빌드

이 폴더에서 실행한다.

```sh
sh ./build-local.sh
```

Gradle Wrapper로 공식 Pleos NaviHelper와 의존성을 포함해 디버그 APK를 빌드한다. Windows에서는 `gradlew.bat assembleDebug --console=plain`을 실행한다. 설치된 SDK/JDK 경로가 다르면 환경변수와 `local.properties`의 `sdk.dir`를 맞춘다. 예:

```sh
ANDROID_SDK_ROOT=/path/to/Android/sdk JAVA_HOME=/path/to/jdk sh ./build-local.sh
```

결과는 Android Studio Run과 같은 `app/build/outputs/apk/debug/app-debug.apk`다. 첫 빌드는 SDK·Gradle 의존성을 받을 네트워크가 필요하다. 패키지는 `com.scenic.pleos`, minSDK 28, targetSDK 35, compileSDK 37.0이며 Build Tools 36.0.0과 Android Studio JBR 25를 사용한다. 개발용 서명 APK로 실차·스토어 검증을 마친 제품은 아니다.

프로젝트 루트의 `node scripts/test-java.mjs`는 Java 도메인·API 계약 검사를 실행한다. 로컬 Android Studio가 없다면 `JAVA_HOME`·`SCENIC_TEST_JSON_JAR`를 지정하거나 `--download-json`을 사용한다. GitHub Actions에는 Node 검사·Java 검사·공식 SDK를 포함한 Android 빌드를 구성했다. 원격 실행 결과는 저장소 Actions에서 확인한다.

`NationwideCatalog.java`와 서버가 읽는 `../catalog/nationwide.json`은 같은 원본에서 생성한다. 생성 파일을 직접 수정하지 말고 [카탈로그 문서](../catalog/README.md)의 절차를 따른다.

## 차량·위치·저장 경계

자동차 하드웨어·라이브러리는 optional이며 표준 Android Car API를 reflection으로 사용한다. AAOS에서 차량 속도·UX 상태를 읽지 못하면 조작을 보수적으로 제한한다. `distractionOptimized=true`로 OS 제한을 우회하지 않는다. 일반 Android의 시연은 실제 정차 여부를 검증하지 않는다.

현재 위치는 최근 30초 이내의 유효한 Android 좌표를 사용한다. 선택한 출발 좌표와 목적지는 경로 비교를 위해 로컬 서버와 Kakao에 전달한다. AI 코스 찾기는 좌표를 TourAPI·Kakao에 전달하고 후보 명소와 시간·풍경·체류·복귀 조건을 OpenAI에 전달한다. 음악 추천에는 경로 제목·풍경·시간·취향을 사용하며 원본 GPS·개인 영상은 OpenAI로 보내지 않는다. 목적지 이름에서 관심 지역은 드러날 수 있다. 순정 내비 요청 시 장소 이름·좌표는 Pleos Navi Service에 전달한다. 공개 출발지와 실제 GPS는 분리되어 있다.

조건·목적지·서버 주소 변경, 취소·화면 전환·백그라운드 이후 과거 응답을 새 조건에 적용하지 않는다. 백그라운드에서 GPS·차량 리스너와 앱 내부 미디어를 중지한다. 실제 이동·차량 UX 제한 중에는 목적지 변경과 촬영·음악 등 조작을 제한한다.

샘플 장면의 경로·구간·시각·사진 식별자와 공유 미리보기 여부는 최대 10,000건을 기기 안에 저장한다. 자동 삭제하지 않으며 한도에서는 새 저장을 중단한다. 이전 버전에서 이미 삭제된 기록은 복구하지 못한다. 개인 영상은 파일 선택기로 가져오며 원본 접근 권한이 사라지면 다시 가져와야 한다. 새 영상의 월별 묶음은 촬영 메타데이터 날짜를 우선 사용하고 없으면 가져온 날짜를 사용한다. 기존 기록은 기록일을 유지한다. 사진·영상 서버 업로드나 사용자 간 공유·클라우드 백업은 없다. Pleos FusedLocation SDK·차량 카메라·실차 자동 촬영·영상 장면 분석은 연결되지 않았다. 도로 조회가 차창 조망·현장 통행·주차·영업 여부를 보장하지 않는다.

최신 자동 검사와 Pleos 화면 확인, 실제 GPS·실차 등 남은 검증 범위는 [검증 기록](../docs/VALIDATION.md)에 기록한다.
