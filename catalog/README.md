# 전국 관광 코스 카탈로그

한국관광공사 TourAPI의 실제 관광지 기초정보를 이용해 준비한 **680개 코스 조합**, **1,822개 서로 다른 관광지**, **17개 관광권역**이다. 각 권역에 40개 조합을 마련했다. 한국관광공사가 선정하거나 검증한 공식 여행 코스가 아니다.

## 출처와 범위

- 원자료: [한국관광공사 국문 관광정보 서비스](https://www.data.go.kr/data/15101578/openapi.do), `KorService2/areaBasedList2`, `contentTypeId=12`.
- 실제 취득 시각은 JSON의 `source.fetchedAt` 및 `tourapi-snapshot.json`의 `fetchedAt`에 기록한다.
- 조회 당시 법정동 시도 목록 16개에 대해 제목순 첫 페이지를 최대 300건씩 취득했다. 요청별 반환 건수와 API 전체 건수는 스냅샷 `requests`에 기록한다. 전국 관광지의 전수 목록은 아니다.
- 4,269건의 응답에서 좌표와 필수정보를 확인해 4,264개 원자료 관광지를 보관했다. 최종 조합에는 그중 1,822개를 사용했다.
- 각 관광지는 실제 `contentid`를 `id`로 유지한다. 제목, 주소, WGS84 좌표, 법정동 코드, 분류 코드, 최종수정 시각만 보관하며 이미지·이미지 URL·상세 소개문은 포함하지 않는다. `sourceUrl`은 이용조건과 API 설명을 제공하는 공공데이터포털 원문이다.
- 원자료 이용조건은 위 공공데이터포털 원문을 따른다. 출처 표시는 “관광지 기초정보: 한국관광공사 TourAPI. 코스 조합: Scenic Pleos 자체 생성.”이다.

## 조합과 거리·시간

- 같은 관광권역, 같은 원자료 시군구, 같은 육지/주요 섬 그룹 내에서 가까운 2~4개 관광지를 묶는다.
- 알려진 도서지역 주소와 섬 단독 분류 관광지는 보수적으로 제외한다. 제주는 제주 본섬, 거제·남해·진도·강화 등은 각각의 그룹으로 분리한다. 이 필터는 해안선 GIS나 실제 도로 연결성을 검증한 결과가 아니다.
- 산·봉우리(`NA010100`), 폭포(`NA010300`), 트레킹 코스(`VE040300`)와 정상·국기봉·등산로·둘레길·탐방로 명칭을 제외해 산 정상이나 도보 전용 코스를 차량 목적지로 제시하는 위험을 줄였다. 남은 관광지 역시 주차 지점이나 차량 진입로를 검증한 목적지는 아니다.
- 모든 지점 쌍은 250m 이상·20km 이내이고, 방문 순서의 한 구간은 최대 15km, 직선 구간 합은 최대 35km다. 가능한 방문 순서 중 직선 구간 합이 가장 짧은 순서를 선택한다.
- 정지점 집합이 같은 코스는 순서가 달라도 하나로 센다. 한 정지점만 추가·삭제한 조합도 제외한다. 한 관광지의 최대 사용 횟수는 권역당 6회다. 시군구별 균형과 관광지의 재사용 횟수를 기준으로 선택한다.
- `distanceKm = round(직선 구간 합 × 1.35, 소수 1자리)`.
- `minutes = 5분 단위 올림(distanceKm ÷ 30km/h × 60 + 정지점 수 × 15분)`.
- 출발지에서 첫 관광지까지의 접근 시간, 실제 도로 우회, 교통, 배편, 영업시간, 주차 여부는 이 수치에 포함하지 않는다. 실제 길찾기 결과와 구분하기 위해 모든 코스에 `metricKind: "heuristic"`, `routeVerified: false`를 기록한다. 현재 조합은 35~145분의 추정 범위를 가진다.
- 앱의 테마 코드 `lake`는 자연·산책, `sea`는 바다·해안, `night`는 도시·문화 분류다. `night`는 야간 운영 또는 조명 설치를 확인했다는 의미가 아니다.

## 파일과 재생성

- `tourapi-snapshot.json`: 실제 응답에서 필요한 기초 필드만 정규화한 스냅샷. 인증키는 저장하지 않는다.
- `nationwide.json`: 서버와 앱이 공유하는 정규 카탈로그.
- `../android/app/src/main/java/com/scenic/pleos/NationwideCatalog.java`: 정규 JSON과 동일한 코스를 포함하는 오프라인 Android 데이터. Java 메서드 크기 제한을 피하도록 12개 코스씩 메서드를 분리했다.
- 최초 제공한 3개 샘플 코스는 이 카탈로그에 포함하지 않는다. 앱이 별도 유지하는 샘플에는 TourAPI 출처를 소급해서 붙이지 않는다.

네트워크 없이 동일 스냅샷으로 재생성:

```sh
node scripts/build-nationwide-catalog.mjs
```

설정된 인증키로 새 원자료를 취득하고 재생성:

```sh
node --env-file-if-exists=.env scripts/build-nationwide-catalog.mjs --fetch
```

취득은 HTTPS만 이용하며 URL 인코딩된 키를 한 번만 해석한다. 요청 URL이나 원시 네트워크 오류를 로그에 출력하지 않는다. 재생성 실패 시 기존 정규 카탈로그는 덮어쓰지 않는다.

검증:

```sh
node --test tests/nationwide-catalog.test.mjs
```

테스트는 지역 범위, 원자료와의 일치, 좌표, 근거리 조건, 섬 제외 규칙, 중복 집합과 단순 확장 방지, 추정식, Java 데이터 일치, 네트워크 없는 재생성을 확인한다.

## scenery-grid.bin.gz · scenery-grid.json

경로 주변 풍경(해안·큰 물가·터널·전망 포인트·큰 숲)을 250 m 격자로 담은 오프라인 데이터입니다. 서버의 `scenery-grid.mjs`가 선택된 풍경 길의 도로 주변을 측정해 근거 문구로만 사용하며, 어떤 길을 고를지는 바꾸지 않습니다. 파일이 없거나 손상되면 근거 문구 없이 기존 응답으로 동작합니다.

- 다시 만드는 방법은 `tools/scenery-grid/README.md`를 보세요.
- 한계: 도로에서 실제로 보이는지(건물·지형 가림)는 반영하지 않습니다. 숲은 OSM 입력 정도에 좌우됩니다.
