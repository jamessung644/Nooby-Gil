# SCENIC · Pleos

**풍경으로 드라이브를 고르고, 좋은 장면을 월간 리캡으로 남기는 차량용 앱.**

현대자동차 공모전을 위해 개발한 **Pleos용 Android 네이티브 시제품**입니다. **지역 → 실제 풍경 사진 → 관광지 → 맛집 → 주차** 순서로 드라이브를 준비합니다. 지역을 고르면 AI가 공개 사진의 풍경 적합성을 평가하고, 고른 사진의 관광 장소가 최종 목적지가 됩니다. 관광지 주변 식당을 선택하면 주차장을 자동 조회하고, 사용자가 안내 버튼을 누르면 도로를 확인한 뒤 Pleos 순정 내비로 연결합니다. 직접 가져온 영상으로 월간 세로 리캡을 만드는 기능도 제공합니다.

기본 화면은 **발견 / 경로 / 음악 / 리캡 / 맛집·주차 / 기록**입니다. 첫 화면에는 TourAPI에서 직접 수집·검수한 **8개 지역의 실제 공개 사진**을 표시합니다. 경포호·낙산해변·오동도·물건리 방조어부림·동궁과 월지·광치기해변·달맞이길·자라섬 사진이며, 카드에 장소와 출처를 적었습니다. 지역을 누른 다음 표시하는 추천 사진은 최신 TourAPI 응답과 개별 이미지 이용 조건을 확인하고 **OpenAI**로 평가합니다. 접어서 구분한 부산 사진 3곳과 자동 기록 체험은 공개 샘플이며, 리캡의 **내 영상**은 사용자가 직접 선택한 파일입니다. 리캡은 기기에서 실제 MP4로 생성합니다.

주 실행 대상은 `android/`의 네이티브 앱입니다. `web/`의 코스 탐색 화면과 별도로 생성하는 `SCENIC_Demo.html`은 이전 흐름을 보존한 보조 데모입니다. Android가 사용하는 Kakao 지도 페이지도 `web/`에 포함되어 있습니다.

풍경은 **바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시** 중에서 고릅니다. 허용 추가 시간은 빠른 길 대비 더 이동해도 괜찮은 시간이며, +15·+30·+60분 프리셋과 직접 입력을 지원합니다.

### 지역에서 관광지·맛집·주차로 이어지는 흐름

1. **발견**에서 8개 지역 중 한 곳을 고르거나 **다른 지역 검색하기**를 사용합니다. 지역 카드는 탐색 시작점이며 실제 방문 장소는 다음 단계에서 정합니다.
2. TourAPI의 이용 조건·좌표가 확인된 관광 사진을 조회합니다. 명백한 실내 시설·기념물·도보 전용 장소 등을 메타데이터로 걸러내고, OpenAI가 실제 사진에서 풍경 감상이 중심인지 평가합니다. AI 평가를 완료하지 못하면 **거리순·AI 사진 분석 미사용**임을 표시합니다.
3. **이 풍경 보러 가기**를 누르면 그 사진의 **관광 장소가 최종 목적지**가 됩니다. Kakao 도로 끝점이 장소 좌표 150m 이내인지 확인하며 지역 탐색 중심으로 돌아오는 경로를 붙이지 않습니다.
4. **다음 · 이 풍경 주변 맛집 찾기**에서 관광지 주변 3km의 식당을 봅니다. 지역 음식 힌트를 선택하면 실제 음식점·카페 분류의 Kakao 키워드 검색 결과를 관련도순으로 좁힙니다. 커피·황남빵 검색도 카페를 포함하며, 관광지·쇼핑 시설·분류 미확인 결과와 임의 평점·리뷰 점수는 표시하지 않습니다.
5. 식당을 고르면 그 식당 좌표를 기준으로 주차장을 **자동 조회**합니다. 최대 45개 등록 장소를 3페이지까지 확인해 **최신 빈자리 확인 → 미확인 → 만차** 순으로 최대 10개를 제안합니다. 연결된 7개 도시의 공식 공급 자료와 일치하는 곳은 잔여면·출처와 제공처 관측 시각 또는 조회 시각을 표시합니다. 갱신 시각이 없는 자료에는 **제공처 갱신 시각 미제공**을 알립니다. 미확인 후보 안에서는 공영·공공 표기와 거리를 참고하며 무료 이용·운영 여부를 잔여면에서 추정하지 않습니다.
6. 정차 상태에서 주차 안내 버튼을 누르면 빈자리를 다시 조회합니다. 선택한 곳이 만차이면 유효한 관측 또는 조회 현황에서 빈자리가 확인된 다른 후보를 찾고 도로 확인 후 순정 내비를 요청합니다. 미확인 장소는 별도 **위치로 안내** 확인이 필요합니다. 안내 중에도 1분마다 확인하되, **현재 만차와 대체 빈자리 양쪽의 제공처 관측 시각**이 유효하고 도로·현재 내비 목적지가 확인될 때만 자동 변경합니다. 조회 시각만 있는 자료는 주행 중 자동 변경에 사용하지 않습니다. 지역·관광지·식당 맥락은 보존합니다.

사진 속 정확한 촬영 지점·방향·현재 조망과 주차장 입구·현장 이용조건은 확인되지 않았습니다. 주차 공급 범위는 **서울·강릉·부산·서귀포·대구·인천·여수의 제공 시설 중 매칭된 곳**이며 전국이나 각 도시 전체를 뜻하지 않습니다. 서울·대구의 관측 시각 있는 자료는 10분, 관측 시각 없는 공식 실시간 응답은 조회 후 90초까지 사용하며 잔여면은 도착 전 달라질 수 있습니다. 제주에서는 서귀포만 연결하고 제주시 ITS 기록은 사용하지 않습니다. 미확인 상태를 빈자리로 간주하지 않습니다. 자세한 동작과 도시별 공식 출처는 [지역 드라이브 여정](docs/TOURISM_JOURNEY.md)과 [실시간 주차·만차 대체 안내](docs/LIVE_PARKING.md)에 있습니다.

TourAPI 위치 검색에 풍경 장소가 누락되면 검수한 18개 장소와 원본 스냅샷을 **주변 장소 ID를 찾는 단서**로 사용합니다. 최대 8개 ID를 최신 `detailCommon2`로 다시 조회하고 현재 좌표·반경·공공누리 **제1유형**을 재검증합니다. 최대 4개의 선호 이미지에는 `detailImage2`를 추가 조회해 **그 이미지 자체의 현재 제1유형·장소 ID·이미지 ID**가 맞을 때만 교체합니다. 갱신 실패 시 저장된 선호 URL을 재사용하지 않고 이번 요청에서 확인한 대표 사진을 유지합니다. 공식 `/cms/resource_photo/` 사진도 지원하며, 상세 출처·재수집 방법은 [실제 지역 사진](docs/REGION_PHOTOS.md)에 있습니다.

### 기존 고정 목적지의 경로 비교

1. 발견 화면의 **이미 갈 곳을 정했다면 → 목적지 검색**에서 최종 목적지를 선택합니다.
2. TourAPI에서 목적지 주변의 이용 조건·좌표가 확인된 사진을 찾습니다. OpenAI에 실제 공개 썸네일을 전달해 사진의 풍경과 구성을 평가합니다. AI 평가가 불가능하면 **거리순**임을 표시합니다.
3. 사진 한 장을 고르면 해당 관광 장소가 경유지가 됩니다. 사진을 고르기 전의 최종 목적지와 출발지 설정은 유지합니다.
4. Kakao로 빠른 길과 **선택한 사진 경유** 경로를 조회합니다. 선택 장소의 좌표에서 150m 이내로 접근하는 도로 형상과 허용 추가 시간을 확인합니다.
5. 경로를 선택한 뒤 **순정 내비로 안내**를 누르면 실제 경로의 목적지·경유지를 Pleos로 전달합니다. 순정 내비는 차량 현재 위치에서 다시 계산합니다.

사진의 점수는 **사진 속 풍경**에 대한 AI 평가입니다. 사진 좌표는 관광 장소의 위치이며, 정확한 촬영 지점·방향·시기·차창 조망을 확인한 것이 아닙니다. OpenAI가 도로를 만들거나 실제 주행 경관을 보장하지 않습니다. 사진 수집은 TourAPI, 이미지 평가는 OpenAI, 순정 내비 연결은 Pleos NaviHelper가 담당합니다. **Gleo AI의 사진 API를 호출하는 구현은 아닙니다.** 상세 흐름과 출처는 [목적지 주변 사진 추천](docs/DESTINATION_PHOTOS.md)을 참고하세요.

고른 장소의 도로를 확인할 수 없거나 추가 시간을 초과하면 이유와 함께 빠른 길만 제안하며, 사용자가 직접 선택해야 합니다. 고른 사진을 다른 장소로 바꾸지 않습니다. 사진 선택은 30분 또는 서버 재시작 후 만료될 수 있으며, 만료 시 사진을 다시 불러오도록 안내합니다. 이 목적지 경로 비교에는 체류 시간이나 출발지 복귀 시간을 포함하지 않습니다.

사진을 선택하지 않은 기존 **풍경 조건 경로 비교**도 사용할 수 있습니다. 이 경우 저장소의 TourAPI 출처 카탈로그와 장소 제목·위치 단서로 후보를 고르며 OpenAI 이미지 평가나 실시간 TourAPI 사진 조회를 사용하지 않습니다. **사진 없이 빠른 길**은 추가 시간 0분으로 목적지까지의 빠른 길을 요청합니다.

**AI 코스 찾기는 별도 흐름입니다.** 발견 화면의 **부산 샘플·내 관찰 기록 펼치기 → AI 코스 찾기**에서 현재 위치 또는 서울시청 공개 시연 출발지를 선택합니다. **풍경을 지나가기**는 체류 0분, **명소에서 머무르기**는 장소별 15분 또는 30분입니다. **출발지로 돌아오기**를 켜면 실제 복귀 구간까지 Kakao로 조회하고 전체 시간 예산에 포함합니다. 순정 내비에 같은 장소를 전달할 수 있도록 복귀 코스는 2곳, 편도 코스는 2~3곳을 선택하고 그 장소만으로 도로를 조회합니다. 최초 UI 설정은 복귀 켜짐·체류 0분이며 이후 선택을 기기에 저장합니다. 전국 준비 코스는 별도 탐색이며 이 AI 시간 조건을 재계산하지 않습니다.

## 시연 순서

아래 실행 설정을 마친 뒤 Pleos를 **P·0km/h** 상태로 두고 진행합니다.

1. **발견**에서 지역을 고르고 실제 풍경 사진의 출처·이용 조건과 **AI 이미지 평가 / 거리순** 상태를 확인합니다.
2. **이 풍경 보러 가기**로 사진 장소까지의 경로를 확인합니다. **다음 · 이 풍경 주변 맛집 찾기**에서 음식 종류를 고르고 식당을 선택하면 주차장이 자동 조회됩니다. 빈자리와 제공 시각을 확인하고 안내 버튼을 누르면 재조회·도로 확인 후 순정 내비로 연결합니다. 미확인 주차장은 별도 확인을 거쳐 위치 안내를 선택할 수 있습니다.
3. **발견 → 부산 샘플·내 관찰 기록 펼치기 → AI 코스 찾기**에서 시간·풍경·체류·복귀 여부를 정하고 **서울시청 출발 · 데모** 또는 **내 주변 코스 찾기**를 선택합니다. 실제 명소 조합과 도로 조회를 체험합니다.
4. 같은 샘플 영역의 **자동 기록 체험 · 18초**에서 시연을 시작합니다. 필요하면 분위기 음악과 내 피드의 공유 미리보기를 켭니다. 샘플 장면 3개가 기록에 저장됩니다.
5. **발견 → 내 영상으로 리캡 만들기 → 내 영상 가져오기**에서 영상 파일을 선택합니다. 포함할 장면 최대 6개와 각 1~8초 구간을 고르고 미리 본 뒤, 음악·메모를 넣어 생성합니다. **동영상 저장**으로 갤러리에 저장할 수 있습니다. 공개 사진은 **샘플 사진으로 전환**에서 별도로 체험합니다.
6. **음악**에서 취향을 선택해 AI 추천과 이유를 확인합니다. **노래 재생**으로 열린 공식 음악 페이지에서 재생한 뒤 **작게 보기**를 누르면 경로 화면과 함께 사용할 수 있습니다. **크게 보기**로 복원하고 **재생 종료**로 닫습니다. **분위기 음악 미리 듣기**는 앱의 자체 합성 음악을 재생합니다.
7. **맛집·주차**의 **주차 확인 내용 기록**에는 직접 확인한 근거를 남깁니다. 이 수동 메모는 실시간 잔여면과 별개입니다. 현장에서 만차·입차 불가라면 경로 화면의 **만차·입차 불가 · 다른 주차장 찾기**로 해당 장소를 제외합니다. 자동 확인은 앱에서, 알림 권한이 있으면 알림에서도 중단할 수 있습니다. 기존 고정 목적지 경유 모드는 발견 화면의 **목적지 검색**에서 따로 체험할 수 있습니다.
8. 경로 선택 후 **순정 내비로 안내**를 누르면 Pleos 내비에 목적지·경유지를 전달합니다. 실제 출발지는 차량 현재 위치이고, 선택한 공개 시연 위치로 차량 GPS가 바뀌는 것은 아닙니다. 요청 결과와 순정 내비의 경로를 확인합니다. 자세한 범위는 [순정 내비 연결](docs/NATIVE_NAVIGATION.md)에 있습니다.

개인 리캡의 길이는 선택한 구간 합계에 출처·음악 안내 3초를 더한 값입니다. 입력 영상은 1초~1시간·512MB 이하이며 기기에서 읽을 수 있는 파일이어야 합니다. 원본 소리는 넣지 않고 앱의 합성 음악을 사용합니다. 파일을 옮기거나 지워 접근할 수 없게 되면 다시 가져와야 합니다. 목록에서 제거해도 원본과 이미 갤러리에 저장한 리캡은 삭제하지 않습니다.

현재 위치를 출발지로 사용할 수도 있습니다. Android 위치 권한과 최근 국내 GPS 수신이 필요하며, 수신 실패를 부산역 출발로 자동 대체하지 않습니다. 에뮬레이터 GPS는 개발 컴퓨터의 실제 위치와 다를 수 있습니다.

음악 추천은 선택 경로의 제목·풍경·예상 시간과 사용자가 고른 취향(분위기에 맞게·어쿠스틱·차분하게·경쾌하게·가사 없이)을 사용합니다. AI는 등록된 목록 중에서 고르며 새 곡이나 플레이리스트를 생성하지 않습니다. **노래 재생**은 SCENIC 내부의 공식 음악 웹 화면을 엽니다. **작게 보기**로 오른쪽 아래 작은 창으로 줄여 경로를 함께 볼 수 있고, **크게 보기**로 같은 플레이어를 복원합니다. 크기 변경·탭 전환으로 페이지를 다시 로드하거나 종료하지 않습니다. **재생 종료**는 플레이어를 종료합니다. **외부 앱에서 열기**는 같은 목록을 공식 앱 또는 브라우저로 연결합니다. 실제 재생 시작은 별도로 필요할 수 있으며 내부 웹 로그인은 지원하지 않습니다. 작은 창은 SCENIC 안에서만 유지되고 앱을 나가거나 차량 조작 제한이 발생하면 종료됩니다. 리캡의 배경음악은 외부 음악 서비스와 별개로 앱에서 합성합니다.

### 1. 로컬 API 서버 실행

저장소를 내려받은 뒤 프로젝트 폴더에서 설정 파일을 준비합니다. 기존 `.env`가 있으면 그대로 유지합니다.

```sh
git clone https://github.com/jamessung644/scenic-pleos.git
cd scenic-pleos
cp -n .env.example .env
```

사용할 기능의 키를 로컬 `.env`에 설정한 뒤 서버를 시작합니다.

```sh
npm start
```

서버는 `--use-system-ca`로 운영체제의 신뢰 인증서를 함께 사용합니다. HTTPS 인증서와 호스트 검증은 유지합니다. 공식 주차 현황의 공개 GET·POST 조회에는 추가 API 키가 필요 없으며 주변 장소 검색·도로 조회에는 기존 Kakao 키를 사용합니다.

개발 컴퓨터의 기본 주소는 `http://127.0.0.1:4173`입니다. 터미널을 실행한 상태로 유지하고, 키나 서버 코드를 바꿨다면 서버를 종료한 뒤 다시 시작합니다. macOS에서는 프로젝트 루트의 `sh scripts/start-local-server.command`로 같은 프로젝트의 시연 서버를 다시 시작할 수도 있습니다.

**설정된 Windows 환경에서는 `Start-SCENIC.cmd`를 더블클릭합니다.** 기존 `.env`를 보존하고, 같은 프로젝트의 서버와 Pleos 에뮬레이터를 재사용하거나 시작합니다. 빌드된 최신 `app-debug.apk`가 설치본과 다를 때만 갱신합니다. 자세한 사용법은 [Windows 실행 안내](WINDOWS-실행안내.txt)에 있습니다.

### 2. Android Studio에서 앱 실행

1. Android Studio에서 저장소 하위 **`scenic-pleos/android`** 폴더를 엽니다.
2. Gradle Sync 후 실행 구성 **app**, 기기 **Pleos Connect v2.1.0**을 선택하고 Run을 누릅니다.
3. 앱의 **설정 → API 서버 연결**에 `http://10.0.2.2:4173`을 입력하고 **저장 및 확인**을 누릅니다.
4. Kakao Maps를 활성화하고 웹 도메인에 `http://10.0.2.2:4173`을 등록합니다. 개발 컴퓨터 브라우저도 사용한다면 `http://127.0.0.1:4173`을 추가합니다.
5. 지도 연결이 되지 않으면 Pleos의 **차량 설정 → 연결 → Wi-Fi → AndroidWifi** 연결을 확인합니다. 차속 미확인으로 앱이 잠기면 **설정 → 차량 · 위치 연결 정보 → 차속 권한 요청**을 확인합니다.

`10.0.2.2`는 Android 에뮬레이터에서 개발 컴퓨터에 접근하는 주소입니다. 물리 기기 연결은 별도 서버·네트워크 구성이 필요합니다. 자세한 실행·문제 해결 절차는 [Android Studio 실행 안내](docs/ANDROID_STUDIO_START.md), [API 설정](docs/API_SETUP.md)에 있습니다. 해당 문서의 `pleos-drive`는 개발 당시 폴더명이며, 새로 내려받은 저장소에서는 `scenic-pleos`에 해당합니다.

### 환경변수

| 이름 | 용도 |
| --- | --- |
| `KAKAO_REST_API_KEY` | 목적지·음식점·주차장 검색과 도로 조회 |
| `KAKAO_MAP_JS_KEY` | Kakao 배경 지도 표시; Maps 활성화·웹 도메인 등록 필요 |
| `OPENAI_API_KEY` | 공개 사진 이미지 평가, AI 코스 조합과 플레이리스트 추천 |
| `OPENAI_MODEL` | 사진·코스·음악 추천 모델; 사진 평가는 이미지 입력을 지원해야 함 |
| `PORT` | 로컬 서버 포트 설정 |
| `TOUR_API_KEY` | 목적지 주변 사진과 AI 코스의 관광지 조회·카탈로그 갱신; 기존 카탈로그 기반 경로 비교에는 불필요 |

비공개 API 키는 서버 `.env`에서만 관리하고 Git·소스·APK에 넣지 않습니다. 앱에는 서버 주소만 입력합니다. 지도 JavaScript 키는 지도 SDK가 사용하는 공개 클라이언트 설정으로 지도 페이지에 전달됩니다.

지역·목적지 검색어와 선택한 출발·목적지·풍경 경유 좌표, 주변 장소 검색 기준 좌표·음식 키워드는 로컬 서버와 Kakao에 전달됩니다. **사진 추천은 지역 탐색 중심 또는 고정 목적지의 좌표·반경을 TourAPI에, 공개 관광 사진의 썸네일 URL·장소명·식별자를 OpenAI에 전달**합니다. 사용자의 개인 사진·영상은 사진 평가에 보내지 않습니다. AI 코스 찾기는 출발 좌표를 TourAPI·Kakao에, 후보 명소와 시간·풍경·체류·복귀 조건을 OpenAI에 전달합니다. 음악 추천에는 경로 제목·풍경·시간·선택한 취향을 사용하며 원본 GPS·사진·영상·청취 기록은 보내지 않습니다.

가져온 영상·관찰 기록·주차 메모는 기기에 저장하고 리캡도 기기에서 생성합니다. 순정 내비를 요청하면 선택한 장소 좌표와 이름이 Pleos Navi Service에 전달됩니다. 음성 메모 버튼은 설치된 음성 입력 앱을 열며, 음성이 해당 제공자에게 처리될 수 있음을 화면에 알립니다.

다중 관광지 AI 코스 생성과 전국 준비 코스 탐색은 발견 화면의 별도 도구에서 사용할 수 있습니다. **부산 샘플·내 관찰 기록**의 3곳은 공개 예시이며 지역별 실제 사진 검색 결과와 구분합니다. 보조 웹 데모는 `node scripts/build-standalone.mjs`로 생성한 뒤 `dist-offline/SCENIC_Demo.html`을 열어 확인할 수 있습니다.

## 개발과 검증

프로젝트 루트에서 실행합니다.

```sh
npm test
npm run check
node scripts/test-java.mjs
sh tests/kakao-map-native/run.sh
sh tests/scenic-capture/run.sh
sh tests/youtube-music/run.sh
sh tests/music-web/run.sh
sh android/build-local.sh
```

`scripts/test-java.mjs`는 운영 코드의 Java 도메인·API 계약 검사를 Windows와 macOS/Linux에서 실행합니다. 로컬 Android Studio의 JDK와 JSON 구현을 찾으며, 별도 환경은 `JAVA_HOME`·`SCENIC_TEST_JSON_JAR`를 지정하거나 `--download-json`으로 해시가 고정된 테스트 의존성을 받습니다. Android 관련 검사는 설치된 SDK/JDK를 사용합니다. 환경에 맞게 `ANDROID_SDK_ROOT`와 `JAVA_HOME`을 지정합니다. `android/build-local.sh`는 Gradle Wrapper로 빌드하며 공식 NaviHelper와 의존성을 함께 처리합니다. Windows에서는 `android` 폴더에서 `gradlew.bat assembleDebug`를 실행합니다.

빌드 결과는 `android/app/build/outputs/apk/debug/app-debug.apk`이며 개발용 서명을 사용합니다. 최초 빌드에는 SDK와 Gradle 의존성을 받을 수 있는 네트워크가 필요합니다.

[GitHub Actions CI](.github/workflows/ci.yml)는 push·pull request 때 Node 22/24의 문법·회귀 검사와 JDK 25의 Java 도메인·API 검사, 공식 Pleos SDK를 포함한 Android 디버그 빌드를 실행하도록 구성했습니다. CI 테스트는 실제 제공자 API나 비공개 키를 사용하지 않습니다. 원격 실행 결과는 저장소의 Actions에서 확인합니다.

## 현재 한계와 미연동 영역

- **안내:** SCENIC 자체 안내는 단계별 시연입니다. 공식 NaviHelper로 순정 내비에 장소를 전달하되 실제 안내·교통·경로선은 순정 내비가 담당합니다. 최대 2개 경유지 제한을 넘으면 임의로 생략하지 않고 안내합니다.
- **촬영·공유:** 18초 시연은 샘플 장면을 자동 저장합니다. 실제 차량 카메라·위치 기반 자동 영상 촬영·영상 분석·공개 공유 서버는 연결되지 않았습니다. 발견 피드의 공유 장면도 이 기기의 샘플 기록입니다.
- **리캡:** 가져온 영상의 선택 구간을 이어 붙이는 방식이며 AI 하이라이트 분석, 자동 월말 예약 제작, 원본 대화 음성 혼합은 지원하지 않습니다. 공개 사진 모드는 별도 샘플 체험입니다. 현재 출력은 360×640·12fps의 시제품 품질입니다.
- **기록 보존:** 풍경 샘플 기록은 10,000개까지 자동 삭제하지 않습니다. 한도에 도달하면 새 저장을 중단합니다. 이전 버전에서 이미 삭제된 기록은 복구하지 못하며, 앱 데이터 삭제·기기 초기화에 대비한 클라우드 백업은 없습니다.
- **맛집·주차:** 음식 키워드는 Kakao 관련도순, 전체 식당은 거리순이며 맛집 평점은 생성하지 않습니다. 주차는 최신 빈자리 확인·미확인·만차 순으로 제안합니다. 연결된 7개 도시에서도 공급 시설과 매칭된 곳만 표시하며, 관측 10분·조회 90초를 넘거나 매칭·조회에 실패하면 미확인입니다. 관측 시각 없는 자료는 갱신 시각 미제공을 표시하고 주행 중 자동 변경에 사용하지 않습니다. 이름의 공공 표기는 실제 이용 가능 확인이 아니며 시설 전용일 수 있습니다. 자체 주차 메모는 수동 기록이고 30일 이후에는 재확인이 필요합니다. 리뷰 자동 분석·요금·운영시간·실제 도보 경로는 제공하지 않으며 거리는 직선거리입니다. 도로 접근 실패·실시간 대안 없음이면 기존 안내를 유지하고 다른 후보를 선택하도록 알립니다.
- **풍경 경로:** 장소 정보와 도로 조건을 기반으로 합니다. 피드의 세 장소는 현장 검증한 주행 코스가 아닙니다. 내 관찰은 출처·날짜를 남기는 로컬 기록이며 실제 차창 조망·날씨·현장 통행을 서비스가 검증했다는 뜻은 아닙니다. 자동차 전용도로 회피 요청이 모든 고속도로 제외를 뜻하지는 않습니다.
- **사진 추천:** 지역 카드는 해당 지역 관광 장소의 실제 공개 사진이며 지역 전체를 망라한 관광 목록이나 현재 현장 영상이 아닙니다. 추천 사진은 탐색 중심 주변의 최신 이용 조건·좌표가 확인된 후보에서 고릅니다. 정확한 촬영 지점·방향·시기는 미확인이며 AI 적합성 필터도 실제 도로 조망·차량 접근을 보장하지 않습니다. AI 평가 실패 시 메타데이터 필터를 거친 후보를 거리순으로 표시하며, Gleo 음성 연동과 사진 검색·비전 API는 연결하지 않았습니다.
- **음악:** 선택한 취향으로 공개 플레이리스트를 추천합니다. 외부 음원의 자동 재생·내부 웹 로그인·지역별 음원 가용성은 지원 또는 검증 범위에 포함되지 않습니다. 시연의 선택적 자동 재생과 리캡에는 자체 합성 음악을 사용합니다.
- **차량·배포:** 표준 Android Car API를 사용하고 AAOS에서 차량 상태를 확인하지 못하면 조작을 제한합니다. NaviHelper는 필요한 서비스·권한·위치 상태에 의존합니다. 실차 안전 인증·스토어 배포와 실도로 주행 검증은 남아 있으며 현재 API 서버는 로컬 개발용입니다.
