# SCENIC · Pleos

**풍경으로 드라이브를 고르고, 좋은 장면을 월간 리캡으로 남기는 차량용 앱.**

현대자동차 공모전을 위해 개발한 **Pleos용 Android 네이티브 시제품**입니다. 사진 중심의 발견 피드와 AI 코스 찾기로 여정을 고르고, 같은 목적지의 빠른 길·풍경 길을 비교합니다. 자동 기록 시연에서 저장한 장면은 음악과 메모가 있는 월간 세로 영상으로 만들 수 있습니다. 음식점 선택 후 주변 주차장 찾기까지 연결됩니다.

기본 화면은 **발견 / 경로 / 음악 / 리캡 / 맛집·주차 / 기록**입니다. 사진은 출처가 표시된 공개 샘플이며, 실제 차량 촬영이나 다른 운전자의 영상이라고 표시하지 않습니다. 장소·도로·AI 조회는 실제 API를 사용하고, 리캡 영상은 기기에서 실제 MP4 파일로 생성합니다.

주 실행 대상은 `android/`의 네이티브 앱입니다. `web/`의 코스 탐색 화면과 별도로 생성하는 `SCENIC_Demo.html`은 이전 흐름을 보존한 보조 데모입니다. Android가 사용하는 Kakao 지도 페이지도 `web/`에 포함되어 있습니다.

## 구현한 기능

| --- | --- | --- |

| 공유 미리보기 | 공유 표시한 내 장면이 발견 피드에 나타남 | 이 기기에서만 표시, 외부 업로드·다른 사용자 콘텐츠 없음 |
| AI 음악 추천 | 경로와 선택한 5가지 취향을 반영해 공개 플레이리스트 6개 중 추천 | OpenAI 실제 API, 공식 음악 페이지 열기 |
| 분위기 음악 | 앱이 합성한 오리지널 사운드 미리 듣기·기록 시연 시작 시 선택적 재생 | 외부 음원 자동 재생과 구분; 리캡에도 자체 합성 음악 사용 |
| 맛집·주차 | 목적지 주변 음식점 → 선택한 식당 주변 주차장 → 경로 목적지 설정 | Kakao Local 실제 검색, 3km·거리순; 리뷰 추출·빈자리 정보 없음 |
| 차량 조작 제한 | 차속·차량 UX 상태에 따라 경로 편집·촬영·음악 조작 제한 | 표준 Android Car API 사용 |

풍경은 **바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시** 중에서 고릅니다. 허용 추가 시간은 빠른 길 대비 더 이동해도 괜찮은 시간이며, +15·+30·+60분 프리셋과 직접 입력을 지원합니다.

### 경로를 비교하는 방식

1. Kakao의 시간 우선 옵션으로 출발지에서 목적지까지의 빠른 길을 조회합니다.
2. 함께 제공하는 TourAPI 출처 장소 데이터에서 선택한 풍경과 위치 조건에 맞는 후보를 찾습니다.
3. 후보 한 곳 인근을 지나 같은 목적지에 도착하는 도로를 Kakao로 조회하고, 도로 형상·거리·추가 시간 등을 검사해 풍경 길을 제시합니다.

**현재 경로 비교는 OpenAI를 사용하지 않습니다.** 장소 제목의 풍경 단서와 도로 조건으로 후보를 고르며, AI가 차창 풍경을 인식하거나 도로를 생성하는 기능은 아닙니다. TourAPI도 경로 비교 시 실시간 호출하지 않습니다.

추가 시간이 0분이거나 조건을 충족하는 풍경 길이 없으면 이유와 함께 빠른 길만 표시합니다. 선택한 풍경을 다른 유형으로 자동 대체하지 않으며, 빠른 길 조회 자체가 실패하면 오류를 표시합니다. 경유 지점의 체류 시간이나 출발지로 돌아오는 시간은 포함하지 않습니다.

**AI 코스 찾기는 별도 흐름입니다.** 발견 화면의 **AI 코스 찾기**에서 현재 위치 또는 서울시청 공개 시연 출발지를 선택합니다. TourAPI 주변 명소 중 OpenAI가 방문 장소를 조합하고, Kakao로 도로 이동 시간을 확인합니다. 총 시간에는 장소별 체류 시간이 들어가며 출발지 복귀는 포함하지 않습니다. 전국 준비 코스 탐색도 이 화면에서 열 수 있습니다.

## 시연 순서

아래 실행 설정을 마친 뒤 Pleos를 **P·0km/h** 상태로 두고 진행합니다.

1. **발견**에서 사진을 살펴보고 장소를 저장하거나 **이 풍경으로 경로 비교**를 누릅니다. 부산역 시연 출발지에서 선택한 장소까지 실제 도로를 조회합니다.
2. **경로**에서 빠른 길·풍경 길을 비교합니다. 직접 검색하려면 해운대해수욕장, 바다·해안, +30분 조건을 사용할 수 있습니다.
3. 다른 여정을 만들려면 **발견 → AI 코스 찾기 → 서울시청 출발 · 데모**를 선택합니다. 기본 90분 조건으로 실제 명소 조합과 도로 조회를 체험합니다.
4. **발견 → 자동 기록 체험 · 18초**에서 시연을 시작합니다. 필요하면 분위기 음악과 내 피드의 공유 미리보기를 켭니다. 샘플 장면 3개가 기록에 저장됩니다.
5. **리캡**에서 월·음악 분위기·기억 메모를 선택하고 영상을 만듭니다. 생성한 세로 MP4를 재생하거나 갤러리에 저장합니다. 기록이 없는 달은 **샘플 리캡 체험**으로 구분합니다.
6. **음악**에서 취향을 선택해 AI 추천과 이유를 확인합니다. **노래 재생**은 공식 음악 페이지를 열고, **분위기 음악 미리 듣기**는 앱의 자체 합성 음악을 재생합니다.
7. **맛집·주차**에서 음식점을 고른 뒤 **주변 주차장 찾기**를 누릅니다. 식당 또는 주차장을 새 경로 목적지로 설정할 수 있습니다. 주차 가능 여부와 빈자리를 보장하지 않습니다.

현재 위치를 출발지로 사용할 수도 있습니다. Android 위치 권한과 최근 국내 GPS 수신이 필요하며, 수신 실패를 부산역 출발로 자동 대체하지 않습니다. 에뮬레이터 GPS는 개발 컴퓨터의 실제 위치와 다를 수 있습니다.

음악 추천은 선택 경로의 제목·풍경·예상 시간과 사용자가 고른 취향(분위기에 맞게·어쿠스틱·차분하게·경쾌하게·가사 없이)을 사용합니다. AI는 등록된 목록 중에서 고르며 새 곡이나 플레이리스트를 생성하지 않습니다. **노래 재생**은 같은 목록을 공식 앱 → 외부 HTTPS → 내부 공식 웹 화면 순서로 여는 기능이며, 실제 재생 시작이나 로그인은 별도로 필요할 수 있습니다. 리캡의 배경음악은 외부 음악 서비스와 별개로 앱에서 합성합니다.

### 1. 로컬 API 서버 실행

저장소를 내려받은 뒤 프로젝트 폴더에서 설정 파일을 준비합니다. 기존 `.env`가 있으면 그대로 유지합니다.

```sh
git clone https://github.com/jamessung644/scenic-pleos.git
cd scenic-pleos
cp -n .env.example .env
```

사용할 기능의 키를 로컬 `.env`에 설정한 뒤 서버를 시작합니다.

```sh
npm start
```

개발 컴퓨터의 기본 주소는 `http://127.0.0.1:4173`입니다. 터미널을 실행한 상태로 유지하고, 키나 서버 코드를 바꿨다면 서버를 종료한 뒤 다시 시작합니다. macOS에서는 프로젝트 루트의 `sh scripts/start-local-server.command`로 같은 프로젝트의 시연 서버를 다시 시작할 수도 있습니다.

**설정된 Windows 환경에서는 `Start-SCENIC.cmd`를 더블클릭합니다.** 기존 `.env`를 보존하고, 같은 프로젝트의 서버와 Pleos 에뮬레이터를 재사용하거나 시작합니다. 빌드된 최신 `app-debug.apk`가 설치본과 다를 때만 갱신합니다. 자세한 사용법은 [Windows 실행 안내](WINDOWS-실행안내.txt)에 있습니다.

### 2. Android Studio에서 앱 실행

1. Android Studio에서 저장소 하위 **`scenic-pleos/android`** 폴더를 엽니다.
2. Gradle Sync 후 실행 구성 **app**, 기기 **Pleos Connect v2.1.0**을 선택하고 Run을 누릅니다.
3. 앱의 **설정 → API 서버 연결**에 `http://10.0.2.2:4173`을 입력하고 **저장 및 확인**을 누릅니다.
4. Kakao Maps를 활성화하고 웹 도메인에 `http://10.0.2.2:4173`을 등록합니다. 개발 컴퓨터 브라우저도 사용한다면 `http://127.0.0.1:4173`을 추가합니다.
5. 지도 연결이 되지 않으면 Pleos의 **차량 설정 → 연결 → Wi-Fi → AndroidWifi** 연결을 확인합니다. 차속 미확인으로 앱이 잠기면 **설정 → 차량 · 위치 연결 정보 → 차속 권한 요청**을 확인합니다.

`10.0.2.2`는 Android 에뮬레이터에서 개발 컴퓨터에 접근하는 주소입니다. 물리 기기 연결은 별도 서버·네트워크 구성이 필요합니다. 자세한 실행·문제 해결 절차는 [Android Studio 실행 안내](docs/ANDROID_STUDIO_START.md), [API 설정](docs/API_SETUP.md)에 있습니다. 해당 문서의 `pleos-drive`는 개발 당시 폴더명이며, 새로 내려받은 저장소에서는 `scenic-pleos`에 해당합니다.

### 환경변수

| 이름 | 용도 |
| --- | --- |
| `KAKAO_REST_API_KEY` | 목적지·음식점·주차장 검색과 도로 조회 |
| `KAKAO_MAP_JS_KEY` | Kakao 배경 지도 표시; Maps 활성화·웹 도메인 등록 필요 |
| `OPENAI_API_KEY` | AI 코스 조합과 플레이리스트 추천 |
| `OPENAI_MODEL` | AI 코스·음악 추천에 사용할 모델 설정 |
| `PORT` | 로컬 서버 포트 설정 |
| `TOUR_API_KEY` | AI 코스 찾기의 주변 관광지 조회·카탈로그 갱신; 같은 목적지 경로 비교에는 불필요 |

비공개 API 키는 서버 `.env`에서만 관리하고 Git·소스·APK에 넣지 않습니다. 앱에는 서버 주소만 입력합니다. 지도 JavaScript 키는 지도 SDK가 사용하는 공개 클라이언트 설정으로 지도 페이지에 전달됩니다.

목적지 검색어와 선택한 출발·목적지·풍경 경유 좌표, 주변 장소 검색 기준 좌표는 로컬 서버와 Kakao에 전달됩니다. AI 코스 찾기는 출발 좌표를 TourAPI·Kakao에, 후보 명소와 시간·풍경 조건을 OpenAI에 전달합니다. 음악 추천에는 경로 제목·풍경·시간·선택한 취향을 사용하며 원본 GPS·사진·영상·청취 기록은 OpenAI에 보내지 않습니다. 리캡은 기기에서 생성합니다. 음성 메모 버튼은 설치된 음성 입력 앱을 열며, 음성이 해당 제공자에게 처리될 수 있음을 화면에 알립니다.

## 프로젝트 구조

| 경로 | 내용 |
| --- | --- |
| `android/` | 발견 피드·차량 연동·기록 시연·리캡 MP4 생성·주변 장소 UI·빌드 스크립트 |
| `server/` | 목적지·음식점·주차장 검색, 도로 비교, AI 코스·음악 추천 |
| `catalog/` | TourAPI 출처 장소·코스·스냅샷 데이터 |
| `web/` | Android용 Kakao 지도 페이지와 이전 보조 웹 UI |
| `tests/` | Node 회귀 검사와 Android API·지도·음악·저장 검사 |
| `scripts/` | 데이터 생성, 문법 검사, 데모·배포 패키징, 서버 시작 도구 |
| `docs/` | 실행 안내, 설계, 출처와 검증 기록 |

다중 관광지 AI 코스 생성과 전국 준비 코스 탐색은 **발견 → AI 코스 찾기**에서 사용할 수 있습니다. 기본 발견 피드의 3곳은 별도의 공개 예시이며 AI가 고른 결과로 표시하지 않습니다. 보조 웹 데모는 `node scripts/build-standalone.mjs`로 생성한 뒤 `dist-offline/SCENIC_Demo.html`을 열어 확인할 수 있습니다.

## 개발과 검증

프로젝트 루트에서 실행합니다.

```sh
npm test
npm run check
sh tests/api-client/run.sh
sh tests/kakao-map-native/run.sh
sh tests/scenic-capture/run.sh
sh tests/youtube-music/run.sh
sh tests/music-web/run.sh
sh android/build-local.sh
```

Android 관련 검사는 설치된 SDK/JDK를 사용합니다. 로컬 빌드 스크립트의 기본 경로가 개발 환경과 다르면 `ANDROID_SDK_ROOT`와 `JAVA_HOME`을 지정합니다. SDK·도구 버전은 `ANDROID_PLATFORM`, `BUILD_TOOLS_VERSION`으로 지정할 수 있습니다. 자세한 내용은 [Android 빌드 안내](android/README.android.md)에 있습니다.

로컬 빌드 결과는 `android/app/build/outputs/apk/debug/scenic-debug.apk`입니다. Android Studio/Gradle이 만드는 `app-debug.apk`와는 별도 산출물이며 개발용 서명을 사용합니다.

도로 수치는 조회 시점에 따라 달라집니다. 기존 Android API 644 checks와 로컬 빌드 5,335 checks 등의 과거 검증은 [검증 기록](docs/VALIDATION.md)에 있습니다. 이 수치를 새 확장 기능 전체의 검사 수로 해석하지 않습니다. 실제 차량 주행·차량 촬영·외부 음악 서비스의 재생은 별도 검증 범위입니다.

## 현재 한계와 미연동 영역

- **안내:** 단계별 시연이며 실시간 턴바이턴·음성 안내·Pleos NaviHelper는 연결되지 않았습니다.
- **촬영·공유:** 18초 시연은 샘플 장면을 자동 저장합니다. 실제 차량 카메라·위치 기반 자동 영상 촬영·영상 분석·공개 공유 서버는 연결되지 않았습니다. 발견 피드의 공유 장면도 이 기기의 샘플 기록입니다.
- **리캡:** 월별로 저장한 샘플 사진을 합성 음악·자막과 함께 실제 MP4로 만듭니다. 실제 주행 영상의 하이라이트 추출, 자동 월말 예약 제작, 대화 녹음·영상 혼합은 연결되지 않았습니다.
- **맛집·주차:** 등록 장소를 거리순으로 찾으며 맛집 평점을 생성하지 않습니다. 리뷰 자동 분석·식당 자체 주차 여부·주차장 실시간 빈자리·요금·운영시간은 확인하지 않습니다.
- **풍경 경로:** 장소 정보와 도로 조건을 기반으로 합니다. 실제 차창 조망·날씨·현장 통행·주차는 검증하지 않았으며, 자동차 전용도로 회피 요청이 모든 고속도로 제외를 뜻하지는 않습니다.
- **음악:** 선택한 취향으로 공개 플레이리스트를 추천합니다. 외부 음원의 자동 재생·내부 웹 로그인·지역별 음원 가용성은 지원 또는 검증 범위에 포함되지 않습니다. 시연의 선택적 자동 재생과 리캡에는 자체 합성 음악을 사용합니다.
- **차량·배포:** 표준 Android Car API를 사용하고 AAOS에서 차량 상태를 확인하지 못하면 조작을 제한합니다. Pleos 전용 SDK·실차 안전 인증·스토어 배포와 모든 풍경 유형의 실도로 주행 검증은 남아 있습니다. 현재 API 서버는 로컬 개발용입니다.
