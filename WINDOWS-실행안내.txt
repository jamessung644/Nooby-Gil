SCENIC · Windows 실행 안내

1. 이 폴더의 Start-SCENIC.cmd를 더블클릭합니다.
2. 로컬 API 서버와 Pleos 에뮬레이터가 준비되면 앱이 열립니다.
3. 앱 설정의 API 서버 주소는 http://10.0.2.2:4173 입니다.
4. P / 0 km/h 상태에서 아래 순서로 확장 기능을 체험합니다.

시연 순서
- 발견: 부산 공개 사진 3곳을 필터링·저장합니다. '사진 근거·내 관찰 보기'에서
  촬영 방향·시기 미확인과 도로 조망 미검증을 확인하고, 직접 관찰한 구간·방향·날짜를 기록합니다.
  내 관찰은 이 기기의 사용자 기록이며 서비스가 현장 검증한 코스는 아닙니다.
- AI 코스: 발견 → AI 코스 찾기에서 시간·풍경·체류·복귀 여부를 고릅니다.
  '풍경을 지나가기'는 체류 0분, '명소에서 머무르기'는 장소별 15분 또는 30분입니다.
  '출발지로 돌아오기'를 켜면 실제 복귀 도로까지 전체 시간에 포함합니다.
  최초 기본값은 90분·복귀 켜짐·체류 0분이며 이후 선택을 기기에 저장합니다.
  '서울시청 출발 · 데모' 또는 '내 주변 코스 찾기'로 TourAPI·OpenAI·Kakao를 실제 조회합니다.
  순정 내비의 경유지 한도를 맞추기 위해 복귀는 2곳, 편도는 2~3곳으로 도로를 조회합니다.
- 경로: 부산역 → 해운대해수욕장 / 바다·해안 / +30분으로 빠른 길과 풍경 길을 비교합니다.
- 자동 기록: 발견 → 자동 기록 체험 · 18초에서 시작하면 샘플 장면 3개를 저장합니다.
  분위기 음악과 내 피드 공유 미리보기는 원하는 경우 켭니다.
- 개인 리캡: 발견 → 내 영상으로 리캡 만들기 → 내 영상 가져오기에서 파일을 선택합니다.
  최대 6개를 포함하고 각 1~8초 구간을 편집·미리 볼 수 있습니다.
  같은 내용의 파일은 중복 제외하며 '날짜별 장면 선택'으로 다른 날의 장면을 고를 수 있습니다.
  새 영상의 월과 날짜는 촬영 메타데이터를 우선 사용하고 없으면 가져온 날짜를 사용합니다.
  기존 기록은 기록일을 유지하며, 선택한 여정 이름도 함께 남습니다.
  음악·메모를 넣어 실제 움직이는 세로 MP4를 생성·재생하고 Movies/SCENIC에 저장합니다.
  출력은 360×640·12fps·H.264 + AAC이며 길이는 선택 구간 합계 + 안내 3초입니다.
  원본 소리는 제외하고 앱의 합성 음악을 사용합니다. 원본 파일을 바꾸거나 업로드하지 않습니다.
  입력은 1초~1시간·512MB 이하이며 파일 선택기에서 접근할 수 있어야 합니다.
  원본을 옮기거나 삭제해 접근할 수 없게 되면 다시 가져와 주세요.
  '샘플 사진으로 전환'은 공개 사진으로 만드는 약 12초 리캡을 별도로 체험하는 기능입니다.
  음성 메모는 버튼을 눌러 설치된 음성 입력 앱을 사용합니다. 앱이 없으면 직접 입력합니다.
- 음악: 5가지 취향으로 AI 추천을 받거나 앱의 오리지널 분위기 음악을 미리 듣습니다.
  노래 재생은 공식 음악 페이지를 열며, 외부 음원 재생·로그인은 해당 서비스에서 진행합니다.
- 맛집·주차: 현재 여정의 방문 장소를 검색 기준으로 고르고 음식점을 선택합니다.
  '주차 확인 내용 기록'에서 가능·불가·확인 필요, 출처와 근거를 저장할 수 있습니다.
  직접 방문·전화·장소 정보에서 사용자가 확인한 기록이며 30일이 지나면 재확인으로 표시합니다.
  주변 주차장으로 경로를 바꾸어도 기존 출발지와 원래 식당 정보를 유지합니다.
  Kakao에 등록된 주변 3km 장소를 조회하며 표시 거리는 직선거리입니다.
  리뷰 자동 분석·실시간 빈자리·요금·도보 길안내는 제공하지 않습니다.
- 순정 내비: 선택한 경로의 '순정 내비로 안내'를 누르면 공식 NaviHelper 3.0.5로
  목적지와 최대 2개의 경유지를 요청합니다. 권한·Navi Service·차량 위치가 필요합니다.
  출발지는 차량 현재 위치이며 공개 시연 좌표로 GPS를 변경하지 않습니다.
  순정 내비가 경로와 시간을 다시 계산하므로 Kakao의 경로선과 달라질 수 있습니다.
  요청 결과와 순정 내비 화면을 확인하세요. 자세한 내용은 docs/NATIVE_NAVIGATION.md에 있습니다.

이미 실행 중인 이 프로젝트의 서버와 Pleos 에뮬레이터는 재사용합니다.
빌드된 최신 app-debug.apk가 설치본과 다르면 앱을 갱신합니다. 실행기가 소스를 빌드하지는 않습니다.
실행기 창은 완료 후 닫아도 됩니다. 서버는 백그라운드에서 실행됩니다.
환경 설정은 이 폴더의 .env에 있으며 실행 시 기존 내용을 보존합니다.
.env는 Git 제외 대상이며 API 키가 들어 있으므로 공유하지 마세요.
키나 서버 코드를 변경했다면 기존 서버를 종료한 뒤 실행기를 다시 실행해야 반영됩니다.

Android Studio에서 코드를 열려면 이 폴더 안의 android 폴더를 선택합니다.
빌드에는 Android Studio JBR 25, SDK 37.0, Build Tools 36.0.0을 사용합니다.
android 폴더에서 gradlew.bat assembleDebug를 실행합니다. 최초 빌드는 네트워크가 필요합니다.
android/build-local.sh도 공식 NaviHelper 의존성을 포함한 Gradle Wrapper 빌드를 사용합니다.
APK 위치: android\app\build\outputs\apk\debug\app-debug.apk
서버·에뮬레이터 실행 로그: .cache 폴더 (실행기로 시작한 경우)

회귀 검사는 프로젝트 루트에서 npm test, npm run check, node scripts/test-java.mjs로 실행합니다.
Java 검사는 로컬 Android Studio의 JDK·JSON 구현을 찾습니다. 별도 환경에서는 JAVA_HOME과
SCENIC_TEST_JSON_JAR를 지정하거나 node scripts/test-java.mjs --download-json을 사용합니다.
GitHub Actions는 Node 22/24 검사와 JDK 25 Java 검사, 공식 Pleos SDK를 포함한 Android 빌드를
push·pull request 때 실행하도록 구성했습니다. 비공개 키·실제 API 호출은 CI에 필요하지 않습니다.
원격 CI 결과는 저장소의 Actions에서 확인합니다.

이전 버전의 에뮬레이터 실행 이력은 이번 수정본의 화면 검증과 구분합니다.

사진과 자동 기록은 출처가 표시된 공개 샘플입니다. 실제 차량 카메라·GPS 기반 자동 촬영은 아닙니다.
공유 미리보기는 이 기기 안에서만 표시하며 다른 사용자 영상·클라우드 업로드는 연결되지 않았습니다.
개인 리캡은 가져온 실제 영상 구간·메모·합성 음악으로 만들고, 샘플 사진 리캡은 별도 모드입니다.
풍경 샘플 기록은 10,000개까지 자동 삭제하지 않으며 한도에 도달하면 새 저장을 중단합니다.
이전 버전에서 이미 삭제된 기록은 복구하지 못합니다. 앱 데이터 삭제에 대비한 클라우드 백업은 없습니다.
SCENIC 자체 안내는 시뮬레이션이고 실제 길안내는 연결된 Pleos 순정 내비가 담당합니다.
실제 차량 주행·촬영·외부 음악 서비스 재생은 별도 검증이 필요합니다.
