SCENIC · Windows 실행 안내

1. 이 폴더의 Start-SCENIC.cmd를 더블클릭합니다.
2. 로컬 API 서버와 Pleos 에뮬레이터가 준비되면 앱이 열립니다.
3. 앱 설정의 API 서버 주소는 http://10.0.2.2:4173 입니다.
4. P / 0 km/h 상태에서 아래 순서로 확장 기능을 체험합니다.

시연 순서
- 발견: 부산 공개 사진 예시 3곳을 필터링·저장하고, 사진에서 경로 비교로 이동합니다.
- AI 코스: 발견 → AI 코스 찾기 → 서울시청 출발 · 데모 → 90분 조건으로 코스를 만듭니다.
  TourAPI 관광지, OpenAI 코스 조합, Kakao 도로 시간을 실제로 조회합니다.
- 경로: 부산역 → 해운대해수욕장 / 바다·해안 / +30분으로 빠른 길과 풍경 길을 비교합니다.
- 자동 기록: 발견 → 자동 기록 체험 · 18초에서 시작하면 샘플 장면 3개를 저장합니다.
  분위기 음악과 내 피드 공유 미리보기는 원하는 경우 켭니다.
- 리캡: 월·음악 분위기·기억 메모를 선택하고 실제 세로 MP4를 생성·재생합니다.
  약 12초, 360×640, H.264 + AAC 영상이며 갤러리의 Movies/SCENIC에 저장할 수 있습니다.
  음성 메모는 버튼을 눌러 설치된 음성 입력 앱을 사용합니다. 앱이 없으면 직접 입력합니다.
- 음악: 5가지 취향으로 AI 추천을 받거나 앱의 오리지널 분위기 음악을 미리 듣습니다.
  노래 재생은 공식 음악 페이지를 열며, 외부 음원 재생·로그인은 해당 서비스에서 진행합니다.
- 맛집·주차: 음식점 선택 → 주변 주차장 찾기 → 식당 또는 주차장을 경로 목적지로 설정합니다.
  Kakao에 등록된 주변 3km 장소를 조회하며 리뷰 분석·주차 빈자리 정보는 제공하지 않습니다.

이미 실행 중인 이 프로젝트의 서버와 Pleos 에뮬레이터는 재사용합니다.
빌드된 최신 app-debug.apk가 설치본과 다르면 앱을 갱신합니다. 실행기가 소스를 빌드하지는 않습니다.
실행기 창은 완료 후 닫아도 됩니다. 서버는 백그라운드에서 실행됩니다.
환경 설정은 이 폴더의 .env에 있습니다. 다운로드 폴더에서 제공한 설정을 복사했으며 실행 시 보존합니다.
.env는 Git 제외 대상이며 API 키가 들어 있으므로 공유하지 마세요.
키를 변경했다면 기존 서버를 종료한 뒤 실행기를 다시 실행해야 반영됩니다.

Android Studio에서 코드를 열려면 이 폴더 안의 android 폴더를 선택합니다.
설치된 Android Studio의 JBR 25, SDK 37.0, Build Tools 36.0.0으로 빌드했습니다.
APK 위치: android\app\build\outputs\apk\debug\app-debug.apk
서버·에뮬레이터 실행 로그: .cache 폴더 (실행기로 시작한 경우)

사진과 자동 기록은 출처가 표시된 공개 샘플입니다. 실제 차량 카메라·GPS 기반 자동 촬영은 아닙니다.
공유 미리보기는 이 기기 안에서만 표시하며 다른 사용자 영상·클라우드 업로드는 연결되지 않았습니다.
리캡은 저장한 샘플 사진·입력한 메모·자체 합성 음악으로 기기에서 실제 MP4 파일을 만듭니다.
현재 안내는 시뮬레이션입니다. 실시간 턴바이턴·음성 길안내·Pleos NaviHelper는 연결되지 않았습니다.
실제 차량 주행·촬영·외부 음악 서비스 재생은 별도 검증이 필요합니다.
