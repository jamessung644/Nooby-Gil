# 현대자동차 공모전 · SCENIC 구현 계획

## 목표와 현재 범위 · 2026-11-05

사용자가 정한 **단일 목적지**까지 빠른 길과 풍경 길을 비교하고, 선택한 경로의 안내·촬영·공유 미리보기 시연과 음악 추천을 연결한다. 기존 여러 관광지 방문 코스의 여유 시간 대신, 빠른 길보다 더 쓸 수 있는 이동 시간을 입력받는다. 경유점은 풍경을 지나는 지점이며 별도 체류 일정이 아니다.

주 실행 대상은 Java 기반 Android 네이티브 앱이다. 비공개 API 키와 외부 호출은 Node.js 서버에서 처리한다. `SCENIC_Demo.html`과 독립 웹 UI는 이전 샘플 탐색을 위한 보조 데모로 유지하며 최신 Android 흐름을 대신하지 않는다.

## 구현 묶음

1. **목적지와 출발지 선택**: Kakao Local 검색 결과에서 한 곳을 선택한다. 최근 Android GPS 출발과 부산역 공개 시연 좌표를 분리한다. 초기 해운대 목적지도 공개 예시로 취급하며 실제 위치를 추정하지 않는다.
2. **같은 목적지 경로 비교**: Kakao 시간 우선 경로를 기준으로, 모든 풍경 또는 바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시 풍경 조건과 0~120분 추가 시간 안의 풍경 길을 찾는다. 서버는 기존 TourAPI 출처 카탈로그에서 경로 주변 후보를 고르고 한 곳 인근을 통과하는 도로를 확인한다. 앱은 목적지 동일성·좌표·도로 형상·시간 상한을 검증한다.
3. **지도와 결과 상태**: 빠른 길/풍경 길 선택에 따라 지도·거리·시간을 함께 바꾼다. 후보 없음·조건 불충족·풍경 공급자 실패는 이유와 빠른 길만 표시하고, 기준 도로 실패는 오류로 표시한다. 조건 변경·취소·화면 이탈 후 오래된 응답을 새 선택에 적용하지 않는다.
4. **안내 시연**: 선택한 경로를 단계별로 보여 주며 풍경 장면 저장을 시연한다. 실제 GPS나 차량 속도를 조작하지 않고, 내비 SDK·음성 안내가 연결된 것으로 표현하지 않는다.
5. **빌트인 캠과 풍경 기록**: 공개 라이선스 사진으로 촬영 미리보기 → 경로에 추가 → 기기 내 갤러리 → 공유 미리보기 흐름을 제공한다. 경로 식별자로 기록을 연결하고 저장 상태를 복원한다. 공유 표시는 기기 안에서만 바뀌며 서버 업로드나 타인 전송은 수행하지 않는다.
6. **음악 추천**: 선택한 경로의 이름·풍경·예상 시간을 기존 음악 추천 API에 연결한다. OpenAI는 등록된 공개 플레이리스트를 선택하고 사용자가 누르면 공식 앱·웹에서 같은 목록을 연다. 경로 비교 자체에는 OpenAI를 사용하지 않는다.
7. **차량 UI와 전달 문서**: 기존 차속·UX 제한, 화면 안전 영역, 작은 화면 스크롤, Asta Sans와 중립 색상 체계를 유지한다. 사용 안내와 배포 압축은 새 Android 흐름을 우선하고 실제 연동·시연·기존 보조 기능을 구분한다.

## 완료 판단에 필요한 확인

| 대상 | 확인할 동작 |
| --- | --- |
| 검색·경로 모델 | 선택한 목적지 ID·이름·좌표 유지, 좌표 순서, 비정상 응답 거부, 빠른 길/풍경 길 구분 |
| 추가 시간·풍경 | 0분·상한·직접 입력, 풍경 후보 없음, 허용 시간을 넘는 도로 제외, 항상 두 경로가 나온다고 가정하지 않기 |
| 상태·취소 | 출발지·목적지·조건 변경, 요청 취소, 백그라운드 전환, 오래된 응답 무시, 오류 후 재시도 |
| GPS와 공개 시연 | 권한 거부·오래된 위치·국내 범위 밖 처리, 부산역 좌표를 현재 위치로 표시하지 않기 |
| 사진·저장 | 실제 차량 촬영이 아님을 표시, 출처·라이선스 접근, 경로별 기록 연결, 기기 내 복원, 공유 상태가 외부 전송을 일으키지 않기 |
| Pleos 화면 | 목적지 선택 → 경로 비교 → 지도/숫자 전환 → 안내 시연 → 촬영 미리보기 → 풍경 기록을 실제 조작으로 확인 |
| 음악·차량 | 선택 경로 조건 전달, 동일 플레이리스트 주소 열기, 차량 제한과 앱 이탈 때 필요한 중지·취소 |
| 배포 | APK·보조 HTML·소스 안내가 같은 범위를 설명하고 비공개 키·서명 개인키·캐시를 제외하기 |

이 표는 검증 기준이다. 검사 실행 결과, 외부 API 응답, Pleos에서 실제로 확인한 범위와 남은 항목은 [VALIDATION.md](VALIDATION.md)에 별도로 기록한다.

## 후속 구현

- 지원 버전·권한을 확보한 실제 내비 연동과 실기기 GPS 검증.
- 허가받은 차량 원본 카메라 접근, 자동 촬영과 실제 영상 저장.
- 사용자 동의를 포함한 공개 공유 서버·접근 제어·기록 관리.
- 실제 도로 조망과 경관 영상에 대한 데이터 수집·평가. 관광지 명칭이나 기존 사진만으로 차창 풍경을 검증했다고 주장하지 않는다.

현재 사진은 부산 실제 장소를 촬영한 공개 자료를 **공유 예시**로 사용한다. SCENIC 사용자 차량이나 다른 운전자의 실제 기록을 수집한 것이 아니다. 실시간 교통 상황의 완전한 반영, 실제 통행·주차·영업시간, 모든 고속도로 배제, 실차 안전 인증은 현재 범위에서 보장하지 않는다.
