# 실시간 주차와 만차 대체 안내

식당 주변 주차장을 찾으면 **빈자리 확인 → 미확인 → 만차** 순서로 제안한다. 최신 빈자리가 확인된 주차장을 우선 추천하고, 안내 직전 선택한 곳을 다시 조회한다. 조회 결과가 없거나 오래됐다는 이유로 주차 가능 또는 만차를 추정하지 않는다.

## 제공 지역과 자료

현재 실시간 공급원은 **서울시 시영주차장**이다. [서울열린데이터광장 시영주차장 실시간 주차대수 정보, OA-21709](https://data.seoul.go.kr/dataList/OA-21709/A/1/datasetView.do)의 공개 Sheet를 조회한다. 공식 페이지는 실시간 갱신 자료로 설명하지만 현장과 5분 이상 차이가 날 수 있다고 안내한다. 2026-11-06 페이지에는 122건이 표시돼 있으며 대상 수는 제공처에 따라 달라질 수 있다.

위치와 주차장 코드는 [서울시 공영주차장 안내 정보, OA-13122](https://data.seoul.go.kr/dataList/OA-13122/S/1/datasetView.do)로 대조한다. 이 안내 자료 자체의 과거 현재주차대수 컬럼은 실시간 공급원으로 사용하지 않는다. 두 자료는 서울특별시 제공·공공누리 제1유형이며 화면에 제공처와 출처 링크를 표시한다. 별도 서울 API 키를 앱에 넣거나 웹사이트의 제3자 비밀키를 가져오지 않는다.

Kakao Local은 관광지·식당 주변 3km의 등록 주차장 위치를 찾는 데 사용한다. 서울 공급 자료와 이름을 정규화해 비교하고, 동일 공급 코드의 안내 좌표가 검색 장소 150m 이내인 경우에만 결합한다. 이름이 비슷한 다른 주차장, 모호하게 중복된 후보, 위치가 일치하지 않는 곳의 수용면을 빌려 쓰지 않는다. **서울 전체 주차장이나 전국 빈자리 제공을 뜻하지 않는다.** 강릉·남해 등 공급 범위 밖의 주차장은 위치 검색을 유지하면서 빈자리는 미확인으로 표시한다.

## 빈자리 판단

| 상태 | 조건 | 안내 동작 |
|---|---|---|
| 빈자리 확인 | 공급처에서 공유 중인 자료, 유효한 수용면·주차대수, 10분 이내 제공 시각, 잔여면 1대 이상 | 우선 추천하고 안내 직전 재조회 |
| 만차 | 같은 검증을 통과한 잔여면 0대 | 자동 대체 후보를 찾고 해당 만차 주차장으로 새 안내를 시작하지 않음 |
| 미확인 | 공급 범위 밖, 매칭 실패, 연결 실패, 잘못된 값·시각, 10분 초과 | 빈자리나 만차로 간주하지 않음; 위치 안내는 사용자가 별도로 선택 |

잔여면은 유효한 전체 수용면에서 현재 주차대수를 뺀 값이다. 음수·비정수·수용면보다 큰 주차대수, 공유 중이 아닌 자료, 미래 제공 시각은 사용하지 않는다. 오래된 관찰과 실패 응답에는 빈자리 수를 넣지 않는다. 무료 이용·운영시간·차종 제한·실제 입구·방문 자격은 잔여면에서 추정하지 않는다.

실시간 원본은 30초, 위치 대조 자료는 24시간 캐시한다. 캐시를 사용하더라도 응답을 만드는 현재 시각으로 유효기간을 다시 평가한다. Android는 서버 응답 시점의 자료 나이에 수신 이후의 단조 증가 시간을 더한다. 기기의 시계나 시간대를 바꿔도 이미 받은 정보를 계속 새 정보처럼 취급하지 않는다.

`parkingStatus`는 `available`, `full`, `unknown` 중 하나다. 각 장소의 `parking` 객체에는 같은 `status`, `availableSpaces`, `totalSpaces`, `observedAt`, `fetchedAt`, `source`, `sourceUrl`, `reason`, `providerId`가 들어간다. `reason`은 `live`, `stale`, `unmatched`, `unavailable`, `unsupported`로 구분한다. 값이 없는 수치·관찰 시각·공급 ID는 `null`이다.

## 목록과 안내 직전 재확인

1. 식당 선택 직후 주변 주차장을 조회한다. 빈자리 확인된 후보가 먼저 표시되며 미확인 후보 안에서는 공영·공공 표기와 거리를 참고한다.
2. 주차 목록이 열려 있고 조작 가능한 정차 상태이면 **45초마다** 갱신한다. 목록에 잔여면, 원본 제공 시각과 출처를 표시하며 자동 새로고침 시 스크롤 위치를 보존한다.
3. 안내 버튼을 누르면 선택한 장소 ID를 `focusId`로 보내 재조회한다. 해당 장소가 만차가 되어 상위 10개에서 빠져도 `focus` 응답으로 현재 상태를 확인한다.
4. 선택한 주차장이 만차이면 같은 응답에서 빈자리가 확인된 다른 후보로 안내하고 변경 이유를 알린다. 대안이 없으면 임의의 미확인 장소로 바꾸지 않는다.
5. 빈자리 미확인 후보는 별도 확인 화면의 **위치로 안내**를 선택했을 때만 등록 위치로 안내한다. 이 선택은 빈자리 확인 성공을 뜻하지 않는다.

식당 자체 주차 메모는 사용자가 직접 확인한 기록이며 실시간 공급 데이터와 별도로 유지한다. 현장에서 만차 또는 입차 불가라면 경로 화면의 **만차·입차 불가 · 다른 주차장 찾기**로 해당 주차장을 이번 목록에서 제외할 수 있다. 이 기록으로 공공 데이터의 잔여면을 수정하지 않는다. 제외 ID는 해당 앱 실행의 여정 선택 동안 메모리에 유지하고, 다음 주차 안내의 확인 서비스에도 전달해 같은 곳으로 되돌아가지 않게 한다. 장기 차단 기록은 아니며 앱 재시작 또는 지역·기준 장소·선택 식당 변경 시 초기화된다.

## 순정 내비 안내 중 확인

사용자가 주차장 안내를 시작하면 Android foreground service가 Pleos 내비 화면에서도 **1분 간격**으로 확인한다. 앱에서 상태와 중단 버튼을 제공하며 알림 권한이 있으면 알림에서도 중단할 수 있다. 서비스는 시스템 종료 후 자동으로 재시작하지 않는다.

자동 변경에는 다음 조건이 모두 필요하다.

- 현재 주차장이 최신 자료에서 만차로 확인됨
- 다른 주차장의 최신 빈자리 확인, 앞서 제외하거나 안내했던 주차장 아님
- 대체 장소까지의 Kakao 도로 응답이 유효하며 끝점이 장소 좌표 150m 이내임
- 순정 내비의 현재 목적지 이름·좌표가 앱이 안내한 주차장과 일치함
- 내비 요청 직전에도 만차와 대안 빈자리 관찰이 유효기간 안에 있음

확인되면 Pleos에 대체 목적지를 요청한다. 순정 내비는 **차량 현재 위치**에서 다시 탐색하며, 대체 목적지 응답까지 확인한 뒤 앱 여정에 반영한다. 지역·관광지·식당 정보는 보존한다. 사용자가 다른 목적지로 바꿨거나 안내를 종료했거나 도착한 경우 확인을 중단한다. 네트워크 오류·오래된 관찰·대안 없음·도로 확인 실패 시 기존 안내를 유지하고 이유를 표시한다.

한 번 시작한 확인은 최대 **3시간**, 자동 목적지 변경은 최대 **3회**이며 변경 사이에는 최소 **2분**을 둔다. 반복 변경으로 같은 주차장을 왕복하지 않도록 이미 안내했던 후보를 제외한다. 자동 변경과 별개로 사용자가 앱 또는 알림의 중단 버튼을 누르면 확인 서비스만 중단하고 내비 안내는 유지한다.

순정 내비와의 초기 연결에서는 새 경로 이벤트와 실제 목적지를 확인한다. SDK 응답을 확인하지 못하면 자동 확인을 중단하며, 이전 경로의 취소 이벤트를 새 안내 실패로 단정하지 않는다. 다른 목적지를 덮어쓰지 않기 위해 목적지 변경 직전에도 내비 상태를 다시 읽는다.

## 검증 범위

자동 검사는 빈자리·만차·미확인 분리, 잘못된 수치와 시각, 캐시·10분 만료, 시계 차이, 이름·좌표 매칭, 상위 목록 밖 `focus`, 만차일 때만 대체 후보 선택을 포함한다. 공개 데이터의 현재 응답, 에뮬레이터 화면, 실제 Pleos 목적지 변경, 제어된 만차 응답 시연은 서로 구분해 기록한다. 최신 실행 결과와 CI는 [검증 기록](VALIDATION.md) 및 해당 변경 브랜치의 Actions 결과에서 확인한다. 이 문서는 실제 차량 주행 또는 현장 입차 성공을 주장하지 않는다.
