# 실제 관광지로 AI 코스 생성

## 기본 흐름

Android의 `내 위치로 AI 코스 만들기`는 버튼을 누른 시점의 최근 GPS, 여유시간, 풍경 조건을 `POST /api/android/plan`으로 전송한다. 위치 갱신마다 자동으로 AI를 호출하지 않는다.

1. TourAPI에서 출발지 반경 최대20km의 관광지 최대30곳을 조회한다. 유효한 ID·이름·주소·좌표를 확인하고 중복, 명백한 산 정상·등산 목적지·폐쇄 안내를 제외한다.
2. OpenAI는 실제 후보 ID 중2~4곳의 방문 순서와 코스 제목·추천 이유를 작성한다. 서버는 알 수 없는 ID·중복·잘못된 형식을 거절한다. 원본 GPS와 좌표는 OpenAI에 전달하지 않는다. 공개 관광지 주소를 통해 대략적인 관심 지역은 드러날 수 있다.
3. Kakao에 `[출발지, 관광지1, …, 마지막 관광지]`의 도로를 요청한다. 도로 조회에는 정확한 출발 좌표가 필요하므로 TourAPI와 Kakao에는 좌표가 전달된다.
4. Kakao 이동시간(초 단위)에 장소별15분 체류를 더한다. 예산 초과나 연결 불가이면 마지막 방문지를 제거하고 도로를 다시 조회한다. 최소2곳, 도로 조회 최대3회, 전체60초 제한이다.
5. 여유시간 안에 들어오는 코스 하나와 실제 도로 좌표를 반환한다. 출발지 복귀는 포함하지 않는다. 실패·후보 부족·가능한 경로 없음은 각각 안내하며, 준비된 코스로 자동 대체해 성공을 표시하지 않는다.

AI는장소·좌표·주행시간을 만들어낼 수 없다. 공급자 경로 조회는 실제 현장 진입·통제·주차·영업시간 검증이나 길 안내를 대신하지 않는다. 풍경 분류는 관광지 이름·분류의 휴리스틱과 선호 조건이며 현장 영상 분석이 아니다.

## 위치와 상태

- 요청 시작에는30초 이내 GPS를 사용한다. 위치가 없거나 국내 서비스 범위 밖이면 현재 위치 추천을 시작하지 않는다.
- `서울시청 기준 데모 생성`은 공개 좌표37.5665,126.9780을 이용하는 별도 클릭 기능이다. 실제 현재 위치라고 표시하지 않고 Android GPS를 바꾸지 않는다.
- 조건·모드·서버 변경, 취소, 백그라운드 전환, 차량 UX 제한으로 무효화된 과거 응답은 적용하지 않는다. 진행 중 여정을 추천으로 교체하지 않는다.
- 실시간 결과에는 출발지부터 계산한 도로가 이미 포함된다. 준비 코스용 별도 도로 조회로 경로·총시간을 덮어쓰지 않는다.
- 비공개 키는 서버 `.env`에만 두며 원문 공급자 오류나 키가 들어간 URL을 클라이언트·로그에 노출하지 않는다.

## 준비된 코스

`준비된 코스 둘러보기`는 전국680개 조합과 기존3개 샘플을 탐색하는 별도 기능이다. 서버 없이 이용할 수 있으며 GPS가 없으면 지역을 직접 선택한다.17개 관광권역·1,822개 관광지의 출처와 재생성 방법은 `catalog/README.md`에 있다.

준비 코스의 시간·거리는 직선거리와 이동·체류 가정을 사용한 추정치다. 실시간 생성의 Kakao 조회값과 구분한다. 기존 `/api/android/recommend`는 등록 후보의 순서를 보완하는 호환용 API로 유지한다.

실제 확인한 범위와 남은 항목은 [검증 기록](VALIDATION.md)을 따른다.
