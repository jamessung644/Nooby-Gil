# SCENIC 화면 디자인 기준

UI UX Pro Max 공식 저장소 `nextlevelbuilder/ui-ux-pro-max-skill`의 `4f2dbb6` 버전을 프로젝트 `.agents/skills/ui-ux-pro-max`에 설치했다. 검색 도구의 자동차 결과는 홍보 사이트, 두 번째 결과는 문서 사이트에 가까웠다. 해당 페이지 구조는 적용하지 않고, 검증된 접근성·터치 가이드와 Minimalism & Swiss Style 원칙을 차량용 화면에 맞게 해석했다.

## 구성
- 발견 → 경로 → 리캡 → 맛집·주차, 네 개 메뉴를 제공한다. 기록은 리캡 하단의 ‘모든 기록 보기’로 통합한다.
- YouTube Music 탭·추천 요청·웹 플레이어 진입을 제거한다. 기록 시연과 리캡의 자체 배경음은 별도 기능이다.
- 발견에서는 목적지 검색과 풍경 사진을, 경로에서는 목적지·추가 시간·대안·지도를 먼저 보여준다.
- 경로 조회 전·조회 중·실패 상태에서도 출발지와 목적지 지도를 유지한다. 도로가 검증되지 않은 상태에서는 위치 마커만 표시하며, 실패 사유와 재시도·장소 변경·주변 주차장 선택을 지도 위에 노출한다.
- 샘플과 기술 설명은 보조 기능에 배치하고, 실제 API 데이터와 시연 데이터의 구분은 유지한다.

## 정보 우선순위
- 발견은 지역 사진·지역명·선택 버튼을 중심으로 구성한다. 지역명 위의 테마 문구를 없애고, 지역명 아래에 여행지 특징을 짧은 한 줄로 표시한다. 출처는 카드에서 확인한다. 상단 메뉴와 중복되는 ‘더 둘러보기’ 영역은 두지 않는다.
- 풍경 선택은 사진·장소명·거리·선택 버튼을 먼저 보여준다. 추천 이유·주소는 사진 정보에 두고 하단에는 탐색 범위 조작만 제공한다.
- 경로는 목적지·실제 경유지·시간·거리·순정 내비 시작을 먼저 보여준다. 경로 선택 후 조건 설정은 접고, 지도 아래에는 식당·주차 진입과 경로 정보를 둔다. 시연·촬영·사진 미리보기는 하단에서 펼친다.
- 맛집·주차는 식당 이름·빈자리·기준 시각·안내 버튼을 강조한다. 주소·전화·출처·운영 조건과 수동 메모는 펼쳐서 확인한다. 식당 선택 후에는 주차 목록에 집중하고, 다른 식당 선택으로 음식점 목록을 다시 연다.
- 리캡은 편집기가 아닌 날짜·장소별 여행 추억 피드다. ‘몇 년 전 오늘’, ‘이번 달’, ‘지난해 몇 월’ 등으로 자동 묶고 사진을 크게 보여준다. 촬영일을 알 수 없으면 가져온 날짜임을 표시하며 기념일로 제시하지 않는다.
- 연결한 빌트인캠 폴더의 새 영상을 읽고 밝기·선명도·중복도를 기준으로 장면을 자동 선별한다. 사진은 자동 보관하고 추억을 열면 영상도 자동 구성한다. 구간·음악·문구를 수동 편집하는 UI는 제공하지 않는다.
- ‘추억 보기’는 화면 높이를 채운 스토리 뷰다. 넓은 화면에서는 왼쪽에 큰 9:16 플레이어, 오른쪽에 날짜·장소를 둔다. 영상 제목은 하단에 배치하고 회색 부가 설명은 표시하지 않는다. 첫 항목인 리캡 영상은 별도 재생 버튼 없이 자동 재생하고 선별 사진을 이어 보여준다. 영상·사진 영역의 좌우 터치로 이전·다음 항목을 열며, 영상 종료 또는 사진 5초 표시 후 자동으로 다음 항목으로 이동한다. 영상·사진 저장은 작은 보조 버튼으로 제공한다.
- ‘모든 기록 보기’에는 개인 영상과 샘플 기록을 날짜·여행별로 모두 표시한다. 원본은 추억 보기에서 분리해 이 화면의 ‘원본 영상’ 목록에서 다운로드하며 `Movies/누비길/원본`에 복사 저장한다. 이전 주행 기록·북마크·촬영 체험도 그 안에서 접근한다. 샘플은 개인 추억과 구분한다.
- ‘정차용 화면’, ‘차창 조망 미확인’ 같은 상시 하단 상태줄·한계 설명과 설명만 담은 안내 영역은 표시하지 않는다. 오류·로딩·주차 빈자리 등 현재 조작에 필요한 정보만 해당 기능 안에 표시한다.

## 색·글자·간격
- 누비길 브랜드는 연속된 길 모양의 N 심볼과 하늘색 도착점, 굵고 촘촘한 한글 워드마크로 구성한다. 헤더·런처·실행 중 작업 아이콘을 같은 형태로 맞춘다.
- 런처는 남색 배경의 adaptive 아이콘을 사용하고 원형 마스크 안전 영역을 지킨다. 알림용 아이콘은 투명 배경의 흰색 실루엣으로 분리한다.
- 바탕 #F3F5F7 / 표면 #FFFFFF / 본문 #18232E / 보조 글자 #526171.
- 주요 버튼 #002C5F, 선택 배경 #E8EEF5, 구분선 #D8E0E8. 녹색은 주차 가능 상태에만 사용한다.
- 기존에 번들된 Asta Sans를 사용한다. 한국어를 지원하며 별도 폰트 다운로드 없이 표시한다.
- 기본 글씨는 공통 크기 함수로 기존보다 2sp만 키워 가독성을 높인다. 제목·본문·보조 문구의 위계와 사용자의 시스템 글자 배율은 유지한다.
- 카드 반경 12dp, 컨트롤 반경 8dp, 기본 버튼 높이 56dp, 버튼 간격 최소 8dp.
- 상단 탭은 흰 배경과 2dp 테두리(#7A8BA1)로 범위를 표시하고, 아이콘과 글자를 함께 중앙 정렬한다. 선택한 탭은 남색 채움과 흰 글자로 구분한다.
- 여백은 8 / 16 / 24 / 32dp, 제목과 본문의 위계를 먼저 맞춘다.
- 좁은 화면은 세로 배치, 긴 제목과 시스템 글자 확대는 내용 기반 높이로 수용한다.
- 차량 시스템 표시줄·화면 잘림의 실제 안전 여백을 재렌더링에도 유지한다. 창 크기·방향·밀도가 바뀌면 다시 계산하며 키보드 여백은 별도로 갱신한다.
- 과도한 장식·그라데이션·회전 배너·음악 추천은 사용하지 않는다.

## 유지할 동작
GPS, 카카오 지도, 목적지·경유 순서 검증, 주차 상태·중단 버튼, 차량 조작 제한, 촬영 시연, 기록과 리캡을 유지한다.
