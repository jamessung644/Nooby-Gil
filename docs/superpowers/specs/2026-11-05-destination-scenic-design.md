# SCENIC · 목적지까지 풍경을 고르는 길

사용자가 정한 하나의 목적지를 유지한다. 기존의 여러 관광지 방문 코스 추천을 기본 화면에서 제거한다. 빠른 길과 풍경 길을 비교해, 추가로 쓸 수 있는 시간 안에서 풍경 경유 구간을 선택한다. 경유점은 별도의 방문 목적지나 체류 일정이 아니다.

## 이번 구현

- Android 네이티브 홈: 목적지 검색/선택, 출발지 선택(현재 위치 또는 부산역 공개 시연 위치), 추가 시간 15/30/60분 및 직접 입력, 모든 풍경 및 바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시 풍경.
- 목적지 검색은 Kakao Local, 경로는 Kakao Mobility 실제 도로 형상과 소요 시간. 풍경 후보는 출처가 있는 기존 관광 데이터에서 경로 주변으로 제한한다. 경치가 실제 차창에 보이는지 검증한 데이터는 아니며 고속도로 완전 배제를 보장하지 않는다.
- 같은 목적지의 빠른 길/풍경 길을 선택하면 지도와 숫자가 함께 바뀐다. 후보가 없거나 API 실패 시 가짜 도로선을 생성하지 않는다.
- 부산역→해운대 공개 좌표 시연을 제공하되 실제 현재 위치로 표시하지 않는다. GPS 출발은 권한과 최신 수신값을 요구한다.
- 안내 시연: 실제 턴바이턴 내비 SDK 대신 단계별 풍경 경로 프리뷰. 실제 차량 속도와 GPS를 바꾸지 않는다.
- 빌트인 캠: 사진을 사용하는 촬영·저장·공유 미리보기 데모. 실제 차량 카메라나 서버 업로드 없음. 모든 이미지에 예시/실제촬영아님 구분.
- 다른 운전자의 영상으로 경로 선택을 돕는 미래 경험은 '공유 예시'로 시연하고 실제 이용자 후기·영상으로 오인시키지 않는다. 직접 저장한 데모는 기기 내 갤러리에 남는다.
- 기존 AI 음악 추천은 선택한 목적지 경로의 분위기를 사용한다. 기존 외부 플레이리스트 연결을 유지한다.

## 화면 기준

흰색/회색/먹색과 Asta Sans 유지. 좌측 약35%에 목적지와 경로 선택, 우측65%에 실제 지도와 풍경 미리보기, 안내 시작. 문구는 목적지/경로/추가시간/촬영 등 필요한 행동 중심. API설정은 설정 안에 유지.

## 검증

검색·응답 파싱·목적지 고정·추가시간 제한·취소·오래된 응답·촬영 저장과 로컬 공유 상태를 테스트한다. 실제 Pleos에서 해운대 검색→경로비교→지도→안내시연→촬영미리보기→갤러리 흐름을 확인한다. 실제 카메라/음성내비/서버공유는 구현하지 않았다고 명시한다.
