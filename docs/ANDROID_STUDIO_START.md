# SCENIC Android Studio 실행 안내

## 프로젝트 열기

Android Studio의 File → Open에서 `pleos-drive/android` 폴더를 연다. Gradle Sync 후 실행 구성 `app`과 기기 `Pleos Connect v2.1.0 / API 34`를 선택하고 Run을 누른다. 상위 `pleos-drive`를 열면 Android 실행 구성이 잡히지 않을 수 있다.

Pleos 차량은 P·0km/h 상태로 둔다. 차속 미확인으로 화면이 잠기면 **설정 → 차량 · 위치 연결 정보 → 차속 권한 요청**을 확인한다. 지원 기기에서 필요한 차량 상태 권한과 UX 제한을 확인한 뒤 시연한다. 일반 Android에서는 실제 정차 여부를 검증하지 않는다.

## API 서버와 지도 준비

1. 개발 컴퓨터의 프로젝트 루트에서 기존 `.env`를 유지하고 필요한 키를 설정한다.
2. Node.js 22 이상에서 `npm start`를 실행한다. 추가 npm 패키지 설치는 필요 없다.
3. 앱의 **설정 → API 서버 연결**에 `http://10.0.2.2:4173`을 입력하고 **저장 및 확인**을 누른다. `/api`나 인증키를 주소에 붙이지 않는다.
4. 목적지 검색·경로 비교에는 `KAKAO_REST_API_KEY`가 필요하다. 풍경 후보는 준비된 장소 데이터에서 읽으므로 이 흐름에 TourAPI·OpenAI 키는 필요하지 않다.
5. 배경 지도에는 `KAKAO_MAP_JS_KEY`, Kakao Maps 활성화, 웹 도메인 `http://10.0.2.2:4173` 등록이 필요하다. 개발 컴퓨터 브라우저도 사용할 때는 `http://127.0.0.1:4173`을 등록한다.
6. 음악 추천을 사용할 때는 `OPENAI_API_KEY`를 추가한다. **발견 → AI 코스 찾기**는 `TOUR_API_KEY`·`OPENAI_API_KEY`·`KAKAO_REST_API_KEY`를 모두 사용한다. `OPENAI_MODEL`의 코드 기본값은 `gpt-6-luna`다.

키나 서버 코드를 변경하면 실행 중인 서버를 Ctrl+C로 종료하고 `npm start`로 다시 시작한다. 새 APK 설치만으로 서버가 갱신되지 않는다. 키 설정 표시는 값 존재만 뜻하며 공급자의 인증·권한·할당량을 보장하지 않는다.

API 키는 서버 `.env`에만 저장한다. Android 입력창·소스·APK·배포 압축에 넣지 않고 기존 파일을 덮어쓰지 않는다. 앱에는 서버 기본 주소만 저장한다. 물리 기기는 에뮬레이터 호스트 별칭 `10.0.2.2`로 연결할 수 없으며 별도의 HTTPS·인증·할당량 구성이 필요하다. 자세한 내용은 [API 설정](API_SETUP.md)을 참고한다.

## 같은 목적지의 빠른 길과 풍경 길 비교

1. **경로** 화면에서 목적지를 누른다. 장소 이름이나 주소로 검색한 뒤 결과 한 곳을 선택한다. 초기 목적지는 변경 가능한 해운대해수욕장 공개 예시다.
2. 출발지에서 **현재 위치 사용**, **부산역 · 시연 출발지**, **서울시청 · 시연 출발지**를 고른다. 현재 위치를 쓰려면 Android 위치 권한을 허용하고 최근 국내 GPS 수신을 기다린다. 에뮬레이터의 GPS는 개발 컴퓨터 실제 위치와 다를 수 있다.
3. **더 돌아가도 괜찮은 시간**을 +15·+30·+60분 또는 직접 입력 0~120분으로 정하고 모든 풍경 또는 바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시 풍경을 선택한다. 이 값은 빠른 길 대비 허용 추가 이동 시간이다.
4. **경로 비교**를 누른다. 조회 중 취소할 수 있으며 목적지·조건을 바꾸면 이전 결과를 새 조건에 적용하지 않는다.
5. 같은 목적지를 유지한 빠른 길과 풍경 길의 예상 이동 시간·거리·추가 시간을 비교하고 하나를 고른다. 풍경 길을 확인하지 못하거나 추가 시간이 0분이면 빠른 길만 표시하고 이유를 안내한다.

부산역 시연은 공개 좌표 `35.1151, 129.0414`를 쓰는 별도 출발지다. 실제 GPS를 바꾸지 않으며 위치 수신 실패를 부산역 출발로 자동 대체하지 않는다. 이 시연도 도로 조회에는 서버와 Kakao REST 키가 필요하다.

빠른 길은 Kakao 시간 우선 옵션의 결과다. 풍경 길은 TourAPI 출처의 준비된 장소 한 곳 인근을 지나 같은 목적지로 가며 자동차 전용도로 회피 옵션을 요청한다. 별도 관광지 체류·출발지 복귀 시간은 더하지 않는다. 조회 결과가 차창 조망·실제 통행·현장 진입·영업·주차를 보장하지 않으며 실시간 내비게이션은 제공하지 않는다.

선택한 출발 좌표와 목적지는 도로 비교를 위해 로컬 서버와 Kakao에 전달한다. 현재 경로 비교는 OpenAI에 보내지 않는다. 음악 추천에는 제목·풍경·시간만 보내며 원본 GPS·영상은 보내지 않는다.

## 안내와 빌트인 캠 데모

경로를 고른 뒤 **안내 시연 시작**을 누르면 실제 주행과 분리된 단계 시연이 진행된다. 시연 중 샘플 장면을 저장하고 종료 후 **풍경 기록**에서 확인할 수 있다. 차량이나 GPS의 실제 이동을 내비게이션으로 추적하는 기능은 아니다.

**빌트인 캠 촬영**을 누르면 공개 라이선스 풍경 사진으로 촬영 결과를 체험한다. **공유 미리보기에 표시**를 정한 뒤 **경로 미리보기에 추가**를 누르면 해당 경로의 데모 장면으로 남는다. 사진은 공유 경험을 보여주는 예시이며 실제 차량 촬영·다른 운전자 실기록·선택 도로의 실제 주행 시야를 뜻하지 않는다.

샘플 기록은 최대 10,000건을 기기 안에 저장하며 자동 삭제하지 않는다. 한도에 도달하면 새 저장을 중단하며 이전 버전에서 삭제된 기록은 복구하지 못한다. 공유 미리보기도 로컬 표시이며 다른 사용자에게 전송하거나 서버에 업로드하지 않는다. 차량 카메라·실차 영상 녹화·자동 촬영·영상 장면 분석은 연결되지 않았다. 사진의 출처와 라이선스는 화면의 **출처 보기**와 [데모 사진 안내](SCENIC_DEMO_ASSETS.md)에서 확인한다.

**내 영상으로 리캡 만들기**는 사용자가 가져온 실제 영상 최대 6개의 1~8초 구간을 선택해 세로 MP4를 만든다. 원본 소리는 제외하며 원본 파일을 변경·업로드하지 않는다. **순정 내비로 안내**는 공식 Pleos NaviHelper 3.0.5로 목적지와 최대 2개 경유지를 요청한다. 차량 현재 위치에서 순정 내비가 경로를 재계산하며 필요한 서비스·권한·위치 조건은 [연결 안내](NATIVE_NAVIGATION.md)를 참고한다.

## AI 플레이리스트

최신 서버와 OpenAI 키를 준비한 뒤 정차 중 **음악**으로 이동한다. AI가 선택 경로의 제목·풍경·시간에 맞는 공개 플레이리스트 하나를 고른다. 선택 경로가 없으면 일반 드라이브 조건을 사용한다. 제목·제작자·추천 이유를 확인하고 **노래 재생**을 누른다.

**노래 재생**은 선택한 목록을 내부 공식 웹 화면에서 연다. 웹에서 재생을 시작한 뒤 **작게 보기**를 누르면 같은 플레이어가 오른쪽 아래 남고 경로 탭을 사용할 수 있다. **크게 보기**는 페이지를 다시 열지 않고 복원하며 **재생 종료**는 플레이어를 닫는다. **외부 앱에서 열기**는 같은 플레이리스트 ID로 공식 YouTube Music 앱 → 외부 HTTPS 링크 → 내부 웹 순서로 시도한다. 추천만으로 재생하지 않는다. 열린 화면에서 별도의 재생 시작이나 로그인이 필요할 수 있으며 자동 재생·지역별 곡 가용성을 보장하지 않는다. 내부 웹에서는 로그인하지 않으며 외부 공식 앱·브라우저를 이용한다. 앱이 백그라운드로 가거나 차량 제한이 발생하면 내부 웹 화면을 닫는다.

## 지도가 나오지 않는 경우

먼저 Pleos의 **차량 설정 → 연결 → Wi-Fi → AndroidWifi**가 현재 네트워크인지 확인한다. Wi-Fi 스위치만 켜져 있고 네트워크는 연결되지 않았을 수 있다. 서버 실행·앱 주소·포트와 Kakao JavaScript 키·Maps 활성화·웹 도메인 등록을 확인한 뒤 지도를 다시 로드한다. `/api/map-config`에서 설정된 것으로 표시되는 것과 실제 지도 로딩 성공은 별개다.

동일 AVD가 이미 실행 중이면 에뮬레이터 명령을 다시 실행하지 않는다. Device Manager의 기존 기기를 이용한다. 재시작이 필요하면 해당 기기를 Stop으로 정상 종료한 뒤 시작한다. 네트워크 연결을 확인하기 위해 Wipe Data나 AVD 삭제를 할 필요는 없다.

## 범위와 검증 기록

현재 주 진입점은 Android 앱이다. **발견 → AI 코스 찾기**에서 전체 시간 예산, 복귀 여부와 장소별 0·15·30분 체류를 선택한다. 복귀는 2곳, 편도는 2~3곳의 실제 도로를 검증한다. 서울시청 공개 출발·내 주변 코스 찾기·전국 준비 코스도 이 화면에서 선택한다. 준비된 코스의 시간은 별도 추정치다. `SCENIC_Demo.html`과 보조 웹은 이전 시연이며 Android의 모든 최신 기능을 제공하지 않는다. 전체 새 기능의 체험 순서는 [Windows 실행 안내](../WINDOWS-실행안내.txt)를 참고한다.

실제 이동·AAOS 차량 UX 제한 중에는 경로 편집과 촬영·음악 등 조작을 제한한다. 일반 Android 시연은 실차 안전 검증을 대신하지 않는다. 도로 조회·공개 출발지 시연·실기기 GPS·실차·음악 재생은 각각 구분해 검증해야 한다. 최신 검사 결과와 확인 범위는 [검증 기록](VALIDATION.md)에 기록한다.
