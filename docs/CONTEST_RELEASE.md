# 누비길 — 심사자용 실행 안내

앱 코드 기준: `main`, 커밋 `6feeca2edf9744d4208f3921328295ed7dd8d9dc`
앱 패키지: `com.scenic.pleos` · 버전: `0.1.0-prototype`
GitHub Release: https://github.com/jamessung644/Nooby-Gil/releases/tag/v0.1.0-contest-20261115

누비길은 Pleos용 Android 시제품입니다. 동봉된 **87초 기능 설명 영상**으로 전체 흐름을 먼저 확인할 수 있습니다. 직접 실행할 때 지도·검색·경로·관광 사진 기능에는 개발 컴퓨터의 로컬 서버와 해당 서비스 API 키가 필요합니다. 개인 영상의 리캡 생성은 기기 안에서 처리합니다.

## 1. 제출 자료와 실행 환경

- **APK:** [`apk/누비길_누비길_release.apk`](../apk/누비길_누비길_release.apk) 또는 위 Release의 APK를 사용합니다. 별도 설치 파일이며 소스 빌드 없이 설치할 수 있습니다.
- **영상:** `NoobyGil_Features_Demo.mp4` — 사진 선택, 경로 비교, 순정 내비 연결, 식당·주차 조회, 주차장 변경 제안, 리캡 생성·저장을 설명합니다.
- **소스:** 동봉된 소스 압축을 풀어 사용합니다. 실행에 필요한 개인 API 키와 서명용 비밀키는 포함하지 않습니다.
- **권장 확인 환경:** Pleos Connect v2.1.0 / Android API 34 에뮬레이터, **2560×1440, 160dpi**. 일반 Android 기기에는 Pleos 순정 내비 서비스가 없을 수 있습니다.
- **서버:** Node.js 22.19 이상인 22 계열 또는 24.6 이상. 서버 실행에는 추가 npm 패키지 설치가 필요하지 않습니다.

새 에뮬레이터에는 APK를 설치하고 앱 목록에서 **누비길**을 엽니다. 개발용 APK가 이미 설치된 기기에서는 서명 차이로 업데이트가 거부될 수 있으므로 별도 에뮬레이터를 사용하는 편이 안전합니다. 기존 앱 제거는 저장된 앱 기록을 지울 수 있습니다.

## 2. 로컬 서버 연결

소스 압축을 푼 프로젝트 폴더를 터미널에서 연 뒤 실행합니다. 최종 제출 커밋은 Release 태그가 가리키는 커밋이며, 위 앱 코드 기준 이후의 변경은 APK와 제출 안내 추가입니다. 기존 `.env`가 있으면 보존합니다.

```sh
cp -n .env.example .env
npm start
```

Windows에서는 파일 탐색기에서 `.env.example`을 `.env`로 복사한 뒤 PowerShell에서 `npm start`를 실행해도 됩니다. `.env`에는 아래 표에서 사용할 기능에 필요한 키를 입력합니다. 키를 추가하거나 변경했다면 실행 중인 서버를 종료하고 다시 시작합니다.

| 설정 이름 | 필요한 기능 / 동작 |
|---|---|
| `KAKAO_REST_API_KEY` | 목적지·식당·주차장 검색, 빠른 길·풍경 길의 도로·시간 조회 |
| `KAKAO_MAP_JS_KEY` | 앱 안의 Kakao 배경 지도. REST 키와 다른 JavaScript 키이며 Kakao Maps 활성화와 웹 도메인 등록 필요 |
| `TOUR_API_KEY` | 지역·목적지 주변의 최신 관광 사진 조회, 별도 AI 코스 찾기의 관광지 조회 |
| `OPENAI_API_KEY` | 공개 관광 사진의 이미지 평가, 별도 AI 코스 찾기의 후보 조합 |
| `OPENAI_MODEL` | 호출할 모델. 예시 설정은 `gpt-6-luna`; 사용 계정의 모델 접근 권한이 필요하며 사진 평가는 이미지 입력을 지원해야 함 |
| `DATA_GO_KR_KEY` | 선택 사항. 한국교통안전공단 주차정보 조회 범위 보완 |
| `PORT` | 기본값 `4173` |

비공개 키는 개발 컴퓨터의 `.env`에만 넣습니다. 앱에는 서버 주소만 입력합니다. JavaScript 지도 키는 지도 SDK의 공개 클라이언트 설정이며, 나머지 비공개 키와 구분해야 합니다.

1. 개발 컴퓨터의 서버 주소는 **`http://127.0.0.1:4173`**입니다. 서버 터미널을 계속 실행해 둡니다.
2. 앱의 **설정 → API 서버 연결**에서 **`http://10.0.2.2:4173`**을 입력하고 **저장 및 확인**을 누릅니다.
3. 앱에 `서버 연결됨`이 표시되는지 확인합니다. `키 설정됨`은 값의 존재만 나타내며, 실제 인증·할당량·응답 성공은 해당 기능을 실행할 때 확인됩니다.
4. Kakao Developers의 웹 도메인에 **`http://10.0.2.2:4173`**을 등록합니다. 개발 컴퓨터 브라우저로도 지도를 확인하려면 **`http://127.0.0.1:4173`**을 추가합니다.

`10.0.2.2`는 Android 에뮬레이터에서 개발 컴퓨터로 연결하는 주소입니다. 서버는 `127.0.0.1`에만 열리므로 물리 차량·휴대전화 연결에는 별도 HTTPS 서버와 네트워크 구성이 필요합니다. 기본 패키지는 로컬 심사용 구성입니다.

### 키가 없거나 외부 서비스가 응답하지 않을 때

- 내장 지역 카드·공개 샘플·준비된 코스 둘러보기와 기기 내 개인 영상 리캡은 외부 AI 평가 성공을 전제로 하지 않습니다.
- **사진 없는 기존 목적지 경로 비교**에는 Kakao REST 키가 필요합니다. 이 방식은 준비된 관광지 카탈로그를 사용하며 OpenAI·TourAPI 실시간 호출이 필요하지 않습니다.
- **최신 주변 관광 사진**은 TourAPI 키가 없으면 불러오지 못합니다. 저장해 둔 사진을 최신 조회 결과로 대체하지 않습니다.
- 관광 사진 조회가 성공하고 OpenAI 키가 없거나 평가에 실패하면 **거리순·AI 이미지 평가 미사용** 상태로 표시합니다.
- **AI 코스 찾기**에는 TourAPI·OpenAI·Kakao REST가 모두 필요합니다. 실패하면 오류와 준비된 코스 이용 안내를 표시합니다.
- 주차 빈자리를 확인하지 못하면 **빈자리 미확인**으로 표시합니다. 키나 네트워크가 없는 경우 영상의 모든 온라인 흐름이 그대로 재현되지는 않습니다.

## 3. 정차 상태와 권한

사진 선택·경로 편집·영상 선택·리캡 재생은 **P·0km/h 정차 상태**에서 확인합니다.

- **차량 상태:** AAOS에서 차속·차량 UX 상태를 읽지 못하면 조작을 제한합니다. **설정 → 차량 · 위치 연결 정보 → 차속 권한 요청**을 확인합니다.
- **위치:** 출발지를 **현재 위치 사용**으로 선택할 때 Android 위치 권한과 유효한 국내 위치가 필요합니다. **부산역 · 시연 출발지**, **서울시청 · 시연 출발지**는 경로 비교용 공개 좌표이며 차량 GPS를 바꾸지 않습니다.
- **순정 내비:** Pleos Navi Service와 순정 Navigation 앱, `NAVI_ROUTE`, `NAVI_ROUTE_SEARCH`, `NAVI_CUSTOM_MAP` 권한을 사용할 수 있는 환경이 필요합니다. 앱은 필요한 권한을 선언합니다.
- **주차 제안:** 순정 내비 화면 위에 변경 제안을 표시하려면 **설정 → 주차 제안 표시 설정**에서 다른 앱 위 표시를 허용합니다. 주차 안내에서 요청하는 알림 권한도 기능 확인 목적에 맞게 허용합니다. 앱 내부의 변경 제안 카드와 시스템 알림·화면 위 표시는 구분됩니다.
- **개인 영상:** 시스템 파일·폴더 선택기에서 선택한 항목의 읽기 권한을 사용합니다. 차량 카메라 권한이나 차량 빌트인캠 SDK 연결을 요구하는 방식은 아닙니다.

## 4. 영상과 같은 순서로 기능 확인

### ① 발견 — 사진으로 목적지 선택

**발견 → 지역 선택 → 사진의 ‘이 풍경 보러 가기’**를 누릅니다. 지역 카드는 탐색 시작점이며 사진 속 관광 장소가 목적지가 됩니다. 기존 목적지를 유지하고 사진 장소만 경유하려면 별도의 **목적지 검색** 흐름에서 **경유지로 선택**을 사용합니다.

### ② 경로 — 풍경과 추가 시간 비교

**경로 설정**에서 보고 싶은 풍경과 빠른 길 대비 허용 추가 시간을 고릅니다. **+15분 / +30분 / +60분** 또는 직접 입력 후 **경로 비교**를 누릅니다. 같은 목적지의 거리·예상 시간·경유 구간을 비교하고 빠른 길 또는 풍경 길을 선택합니다. 조건에 맞는 풍경 길이 없으면 이유와 함께 빠른 길만 표시될 수 있습니다.

### ③ 순정 내비게이션 연결

**순정 내비로 안내**를 누르고 실제 내비 화면의 목적지와 안내 상태를 확인합니다. 전달하는 정보는 **목적지와 최대 2개 경유지**입니다. 순정 내비가 차량 현재 위치에서 경로를 다시 계산하므로 앱의 비교 지도와 경로선·예상 시간이 다를 수 있습니다. 요청 중 표시만으로 연결 완료를 판단하지 않습니다.

### ④ 맛집·주차 — 식당과 주차장 연결

경로 화면의 **다음 · 이 풍경 주변 맛집 찾기** 또는 **맛집·주차**에서 식당을 고르면 주변 주차장을 조회합니다. 확인 가능한 시설은 잔여면과 출처·제공 시각을 표시하고, 미지원·오래된 정보는 **미확인**으로 표시합니다. 안내 직전에 다시 확인하며, 미확인 장소는 위치 안내 여부를 별도로 확인합니다.

### ⑤ 주차 상황 변화 — 변경 제안

주차 안내가 시작된 뒤 유효한 관측 정보에서 만차·곧 만차가 확인되고 대체 시설도 확인되면 **변경 / 유지**를 제안합니다. **변경**을 선택하면 현황과 안내 목적지를 재확인한 뒤 대체 주차장 안내를 요청합니다. **유지**는 현재 안내를 유지합니다.

이 제안은 공급 시설·정보 시각·순정 내비 상태 등의 조건에 따라 발생합니다. 일반 실행에서 즉시 강제로 나타나는 메뉴는 아닙니다. 제출 영상의 **서울 방화역 주차 변경 구간은 시연 데이터**로 상황 변화를 재현했으며 실제 당시 주차 현황을 뜻하지 않습니다. 시연용 주차 데이터 주입 도구는 일반 앱 기능으로 제공하지 않습니다.

### ⑥ 리캡 — 개인 영상 연결·자동 생성·저장

**리캡 → 여행 영상 연결**에서 기기의 영상을 선택합니다. 장면 선별 후 나타난 카드에서 **추억 보기**를 열면 짧은 리캡을 생성·재생합니다. **영상 저장**을 누르고 저장 안내와 앨범의 누비길 폴더를 확인합니다. 폴더 단위 연결은 **빌트인캠 폴더 연결**을 사용하며 앱이 활성 상태일 때 새 파일을 확인합니다.

개인 영상이 없으면 별도의 **샘플 추억 보기**를 이용할 수 있습니다. 모든 기록과 원본 영상은 리캡 하단 **모든 기록 보기**에서 확인합니다. **자동 기록 체험 · 18초**는 발견의 **부산 샘플·내 관찰 기록 펼치기**에 있는 별도 샘플 기능입니다.

## 5. 구현 범위와 영상 해석

- 사진 AI는 공개 사진의 적합성을 평가합니다. 도로를 임의 생성하거나 실제 차창 조망·촬영 방향·현재 풍경을 보장하지 않습니다. Gleo 사진·음성 연동은 구현 범위에 포함하지 않습니다.
- 자동 리캡의 장면 선별은 기기에서 밝기·선명도·장면 차이를 비교하는 방식입니다. 외부 신경망 모델이 개인 영상을 분석하는 기능은 아니며 원본 영상을 업로드하거나 변경하지 않습니다.
- **빌트인캠 폴더 연결**은 사용자가 선택한 저장 폴더를 읽습니다. 차량 카메라 SDK 직접 접근·실차 자동 촬영·클라우드 동기화·사용자 간 공개 공유는 구현하지 않았습니다.
- 주차 공급 범위는 연결된 도시의 매칭 시설에 한정됩니다. 모든 주차장의 실시간 빈자리, 요금·운영시간·도착 시 이용 가능성을 보장하지 않습니다.
- 제출 영상의 순정 내비 화면은 에뮬레이터에서 목적지 전달과 경로 표시를 확인한 장면입니다. 일부 배경 지도 타일은 표시되지 않았으며 영상에 이를 명시했습니다. 실차 주행·안전 인증을 완료했다는 의미는 아닙니다.
- 리캡의 공개 아이오닉 주행 영상은 가져오기·생성·저장 기능 확인용 자료입니다. 부산 실제 주행이나 앱의 차량 카메라 자동 수집 증거가 아닙니다. 영상 끝의 원저작자·CC BY·원본 링크를 유지했습니다.

## 6. 자주 발생하는 문제

| 증상 | 확인할 사항 |
|---|---|
| 서버에 연결되지 않음 | 개발 컴퓨터의 `npm start`, 앱 주소 `http://10.0.2.2:4173`, 포트 일치 |
| 키가 설정돼 있지만 검색·사진·경로 실패 | 해당 공급자의 인증·활성화·할당량, 변경 후 서버 재시작 |
| 지도만 보이지 않음 | `KAKAO_MAP_JS_KEY`, Maps 활성화, 웹 도메인 등록, 에뮬레이터 **Wi-Fi → AndroidWifi** 연결 |
| 사진 목록이 비어 있음 | TourAPI 키·현재 응답·반경·이용 조건. OpenAI 평가 실패와 관광 사진 조회 실패는 별개 |
| 경로가 빠른 길 하나뿐임 | 추가 시간·풍경 조건과 화면의 실패 이유. 풍경 경로가 항상 존재하지는 않음 |
| 순정 내비가 열리지 않음 | Pleos Navi Service·Navigation 앱·관련 권한·차량 위치·네트워크 |
