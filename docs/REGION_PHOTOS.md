# 실제 지역 사진과 풍경 이미지 선별

2026-11-06에 한국관광공사 TourAPI의 장소·개별 이미지 정보를 조회하고 공개 사진을 수집했다. 일반 검색엔진의 임의 이미지를 가져오거나 AI 이미지를 실제 풍경으로 표시하지 않는다.

## 앱에 포함한 지역 사진

| 지역 | 사진의 실제 관광 장소 |
|---|---|
| 강릉 | 경포호(철새도래지) |
| 속초·양양 | 낙산해수욕장 |
| 여수 | 한려해상국립공원 (오동도) |
| 남해 | 남해 물건리 방조어부림 |
| 경주 | 경주 동궁과 월지 |
| 제주 동부 | 광치기해변 |
| 부산 해안 | 해운대 달맞이길 |
| 가평 | 자라섬 |

8개 사진은 **공공누리 제1유형**이며, 원본을 가로세로 비율을 유지해 최대 960×720으로 축소하고 JPEG로 압축했다. 합계 906,405바이트다. 카드에서는 중앙 맞춤으로 표시한다. 이미지 자체에 있는 출처 외에 카드에도 한국관광공사를 표시하며, **지역·사진 출처 → 사진 원본·출처**에서 원본을 열 수 있다. 개별 촬영자 정보는 API가 제공하지 않아 임의 이름을 붙이지 않았다. 제작·촬영 연도 역시 추정하지 않는다.

`android/app/src/main/assets/scenic-regions/manifest.json`에는 장소 ID·장소 좌표·원본 URL·제공 기관·이용 조건·확인 시각·변환 내용·파일 SHA-256을 기록한다. 같은 폴더의 `ATTRIBUTION.txt`에도 출처를 적었다. 자동 검사는 8지역·서로 다른 파일·파일 해시·출처·크기를 확인한다.

## 사용자에게 제안할 사진

`catalog/scenic-photo-curation.json`은 화면 구성을 검토한 **18개 장소**와 선호하는 개별 이미지 ID를 제공한다. 저장된 ID·좌표는 최신 사진을 찾기 위한 단서다. 경로에 사용하는 장소 좌표는 항상 최신 TourAPI 응답에서 확인한다.

- 위치 검색 결과에 누락된 선별 장소는 반경 안의 최대 8개 ID를 `detailCommon2`로 다시 조회한다. 동시에 진행하는 요청은 최대 3개다.
- 선호하는 개별 사진이 있으면 최대 4장에 대해 `detailImage2`를 조회한다. 동시에 최대 2개, 이 단계 전체 9초 제한이며 요청별 최대 4초다.
- 개별 이미지의 장소 ID·이미지 ID·**현재 제1유형**·공식 URL을 모두 확인해야 교체한다. 제3유형이 섞인 갤러리에서 장소 대표 이미지의 허용 조건을 다른 사진에 전파하지 않는다.
- 최신 조회에 실패하거나 허용 조건이 바뀌면 저장된 선호 URL을 재사용하지 않고, 이번 요청에서 이미 검증한 장소 대표 사진을 유지한다. AI 분석을 마친 것처럼 표시하지 않는다.
- 공식 CDN의 `/cms/resource/`와 `/cms/resource_photo/` 두 경로를 허용한다. 동일 호스트의 HTTPS 파일만 사용하며 쿼리·사용자 정보·포트·경로 이동·외부 호스트·리디렉션은 허용하지 않는다.
- 최대 12개 실제 썸네일을 OpenAI에 전달해 자연·수변·해안·넓은 전망·야경 등 풍경 비중과 구성을 평가한다. `landscapeSuitable=true`, 55점 이상, 구체적인 풍경 유형의 사진을 보여준다. 사진 점수는 도로 조망이나 운전 경로의 품질 점수가 아니다.

사진 좌표는 관광 장소 위치다. 정확한 촬영 위치·방향·현재 시야·촬영 시기·항상 같은 풍경이 보임은 확인하지 않는다. 사진 선택 후 실제 도로가 장소 150m 이내에 도착하는지는 경로 서비스에서 별도로 확인한다.

## 실제 API 검증

2026-11-06에 8개 지역 모두 반경 10km로 최신 장소·사진 조회와 OpenAI 평가를 실행했다. 강릉 3장, 속초·양양 7장, 여수 5장, 남해 3장, 경주 6장, 제주 동부 6장, 부산 해안 7장, 가평 1장으로 합계 **38장**이 적합성 필터를 통과했다. 각 지역 요청은 5~17초였고 모두 `vision` 결과였다. 경포호의 `resource_photo` 사진, 보문정·동궁과 월지 갤러리, 부산 달맞이길·광안리 사진을 실제 최신 응답으로 확인했다. 사진 수와 점수·대기시간은 조회 시점과 제공 기관·AI 응답에 따라 달라진다. 이는 8개 지역 전부에서 차량 주행이나 촬영 지점까지 접근을 검증했다는 뜻은 아니다.

## 자산 다시 수집하기

승인된 로컬 `.env`의 TourAPI 키로 실행한다. 키는 앱·명세·커밋에 포함하지 않는다.

```sh
node --env-file=.env scripts/collect-region-photos.mjs
python scripts/prepare-region-photo-assets.py
```

첫 명령은 8개 장소와 개별 이미지의 최신 허용 조건을 다시 확인하고 `.cache/region-photo-import/`에 내려받는다. 확인 실패 시 기존 앱 자산은 변경하지 않는다. 두 번째 명령에는 Python 3와 Pillow가 필요하며, 실제 Android 빌드에는 Python이 필요하지 않다. 사진의 내용이 바뀔 수 있으므로 재수집 뒤 화면과 출처를 검토해야 한다.
