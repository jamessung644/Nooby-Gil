# 서체 · 2026-11-05

Pleos Connect 공식 Typography 가이드의 시스템 UI 서체 Asta Sans를 사용한다.
출처: https://document.pleos.ai/en/docs/connect/guide/docs-design/foundations/typography
폰트 원본: https://github.com/google/fonts/tree/main/ofl/astasans

Android assets와 웹 assets에 동일한 가변 TTF 및 SIL OFL 1.1 라이선스를 포함한다. 본문 400, 주요 제목·버튼 600을 사용한다. 인터넷 폰트 요청 없이 표시하며 단일 HTML에도 폰트와 라이선스를 내장한다. Android 로컬 빌드는 aapt2의 assets 인자를 포함한다. 외부 YouTube Music 페이지의 서체는 변경하지 않는다.

반복 안내·장식 영문·중복 상태 문구를 제거했다. 위치 이용, 외부 전송, 오류, 예상 시간과 복귀 시간 등 판단에 필요한 안내는 유지한다.
