# SCENIC 디자인 레퍼런스

- Figma: https://www.figma.com/design/aKfyvBoH0dR4LCweOPSEUg
- 홈: https://www.figma.com/design/aKfyvBoH0dR4LCweOPSEUg?node-id=4-331
- 음악: https://www.figma.com/design/aKfyvBoH0dR4LCweOPSEUg?node-id=4-470

두 화면은 1280×720 편집 가능한 레퍼런스다. Auto Layout, Material 3 기반 버튼 인스턴스 21개, 텍스트 61개, SCENIC 색상 변수로 구성했다. 현재 버전은 무채색을 중심으로 정리한 자동차 유틸리티 화면이다. 최종 전체 화면 렌더에서 배치, 한글 표시, 텍스트 줄바꿈과 강조 면적을 확인했고, 모든 버튼의 최소 높이가 56px임을 검사했다. Roboto와 Noto Sans KR을 사용한다.

홈은 조건 34% / 경로 66%의 2열 구성이다. 지도 영역은 선택된 기존 번들 코스 ‘춘천, 물빛을 따라서’의 경로선·지점 번호·지명만 표현한 편집 가능한 도식이다. 장식 물길과 임의 도로 이미지는 제거했으며, 실제 길 안내 또는 정확한 지도가 아니다. 음악은 실제 기능인 단일 AI 추천 플레이리스트의 제목·제작자·추천 이유·외부 재생 버튼으로 한정한다. 제목·제작자·이유는 실제 응답을 바인딩할 자리표시자다.

기준 색상은 배경 `#F5F5F5`, 패널 `#FFFFFF`, 본문·주 행동 `#17191C`, 보조 본문 `#656970`, 구분선 `#DFE1E4`, 선택 배경 `#ECEDEF`다. 화면 외곽 24px, 주요 간격 16/24px, 카드 반경 8px, 버튼 반경 6px를 적용했다. 큰 채움 탭은 왼쪽 정렬 텍스트와 하단선으로 바꾸었고, 음악 안내 패널도 흰색으로 정리했다. 채움은 주요 행동에만 사용하며 여정 시작 버튼은 220px, 음악 재생 버튼은 240px로 제한한다. 문구는 ‘드라이브 코스’, ‘드라이브 음악’, ‘재생 안내’처럼 기능을 직접 설명한다. API 서버 설정은 상단 설정 안에 둔다.
