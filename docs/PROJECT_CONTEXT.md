# 현대자동차 공모전 · 프로젝트 맥락

프로젝트: [현대자동차 공모전](https://chatgpt.com/g/g-p-6aead5ade4ac8191a36e0f1b7081540f/project)

## 현재 제품 방향 · 2026-11-05

SCENIC은 **사용자가 정한 목적지 한 곳까지 가는 빠른 길과 풍경 길을 비교**하는 Pleos Android 시제품이다. 기본 흐름은 목적지 검색·선택 → 추가 이동 시간과 풍경 선택 → 같은 목적지의 경로 비교 → 안내 시연 → 빌트인 캠 촬영·공유 미리보기 데모다. 여러 관광지를 방문하도록 목적지를 바꾸거나 체류 일정을 더하는 코스 추천은 현재 기본 경험이 아니다.

초기 공개 예시는 부산역 출발·해운대해수욕장 도착이다. 실제 현재 위치 출발은 Android 위치 권한과 최근 수신값으로 별도 선택한다. 부산역 시연 좌표를 GPS로 표시하거나 GPS 실패 때 자동 대체하지 않는다. 경로 선택은 실제 도로 조회를 사용하지만, 안내 진행과 카메라는 시연이다.

현재 주 실행 대상은 Android 네이티브 앱이다. 독립 웹과 `SCENIC_Demo.html`은 이전 샘플 코스 탐색을 보존한 보조 데모다. 이전 다중 명소 생성 API와 전국 준비 코스 자료도 호환·개발 용도로 남아 있으며 새 기본 화면과 구분한다.

## 구현 결정과 경계

| 영역 | 현재 구현 |
| --- | --- |
| 목적지 | Kakao Local 검색 결과 중 한 곳을 선택하고 ID·이름·좌표를 경로 응답과 대조한다. |
| 경로 | Kakao 시간 우선 빠른 길과, 기존 TourAPI 출처 카탈로그의 풍경 후보 한 곳 인근을 통과하는 풍경 길을 비교한다. 최종 목적지는 같다. |
| 시간 | 0~120분의 추가 이동 시간 상한을 빠른 길 기준으로 검사한다. 관광지 체류나 출발지 복귀 일정은 더하지 않는다. |
| 풍경 | 모든 풍경 또는 바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시 풍경을 선택한다. 후보·도로를 찾지 못하면 이유와 빠른 길만 표시하며, 가짜 도로선을 만들지 않는다. 실제 차창 조망과 모든 고속도로 배제는 보장하지 않는다. |
| 안내 | 단계별 경로·풍경 저장 시연이다. 실제 턴바이턴 내비, 음성 안내, NaviHelper는 미연결이다. |
| 카메라·기록 | 공개 라이선스 사진을 이용한 촬영·기록 데모다. 사진은 실제 부산 장소 자료지만 SCENIC이나 사용자의 차량에서 촬영한 것이 아니다. |
| 공유 | 다른 운전자의 경로 선택을 돕는 미래 경험을 공유 예시로 보여 준다. 저장한 데모 기록과 공유 표시 상태는 해당 기기 안에만 남고 업로드·타인 전송은 없다. |
| 음악 | OpenAI가 목적지 경로의 이름·풍경·시간을 바탕으로 등록 공개 플레이리스트를 고른다. 사용자가 누르면 같은 목록을 YouTube Music 앱·웹으로 연다. 자동 재생은 보장하지 않는다. |
| 차량 | 지원 기기에서 Android Car API 차속·UX 제한을 읽는다. 실제 카메라 권한·차량 제어·실차 안전 인증을 확보한 제품은 아니다. |

목적지 검색과 도로 비교에는 Kakao REST 키, 배경 지도에는 별도 JavaScript 키가 필요하다. OpenAI는 음악 추천에 사용하며 새 경로 비교에서는 호출하지 않는다. 풍경 후보는 함께 배포한 관광 카탈로그를 사용하므로 경로 비교마다 TourAPI를 조회하지 않는다. 출발 좌표와 목적지는 도로 조회를 위해 로컬 서버·Kakao에 전달하지만 원본 GPS·사진·영상은 음악 추천으로 보내지 않는다.

## 원래 아이디어와 이전 논의

원래 아이디어는 AI의 드라이브 코스·명소 추천, 명소에서 촬영한 실제 영상으로 여행지를 고르는 경험, 운전자·경관에 맞춘 음악 추천 및 재생이었다. 현재 시제품은 이 중 **목적지로 가는 길에서 풍경을 선택하고 기록을 다시 경로 선택에 연결하는 경험**을 구체화했다. 실제 차량 촬영과 다른 운전자에게 공개하는 기능은 후속 연동 범위다.

2026-11-04에 다음 대화를 프로젝트로 모아 확인한 기록을 보존한다.

- [사용가능한 API 정리](https://chatgpt.com/g/g-p-6aead5ade4ac8191a36e0f1b7081540f/c/6ae338ee-87dc-83ec-885f-b13249cbc09d): 차량 SDK 종류와 정비센터 추천·예약 가능 여부 논의.
- [프로젝트 구현 요청](https://chatgpt.com/g/g-p-6aead5ade4ac8191a36e0f1b7081540f/c/6aead42f-0b4c-83ee-9bdb-848bcf7fc11f): 풍경·음악 아이디어와 시제품 구현.

이전 정비 아이디어는 후속 후보로 보존한다. 차량 경고는 정밀 고장진단을 뜻하지 않고 실제 정비 예약에는 별도 제휴·연동이 필요하다. 이전 웹의 영상 색상 통계와 사용자 영상 가져오기를 새 Android 빌트인 캠 구현으로 설명하지 않는다.
