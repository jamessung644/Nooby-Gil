# API 준비물과 연결 범위

현재 Android 주 시연은 **목적지 한 곳 선택 → 같은 목적지의 빠른 길·풍경 길 비교 → 안내·빌트인 캠 데모 → 풍경 기록**이다. 경로 비교는 Kakao 자동차 길찾기를 이용하며, 풍경 후보는 TourAPI 출처의 준비된 전국 장소 데이터에서 찾는다. 이 흐름에서 OpenAI로 경로를 생성하거나 TourAPI를 실시간 호출하지 않는다. 음악 추천은 별도의 OpenAI 기능이다.

이 문서는 설정 방법과 구현 범위를 설명한다. 자동 검사, 외부 API 호출, Pleos 화면 확인 결과와 남은 검증은 [검증 기록](VALIDATION.md)을 기준으로 한다.

| 준비물 | 현재 Android에서의 용도 |
|---|---|
| `KAKAO_REST_API_KEY` | Kakao Local 목적지 검색, 같은 출발지·목적지의 빠른 길과 풍경 경유 도로 조회 |
| `KAKAO_MAP_JS_KEY` | Kakao 배경 지도·출발지·목적지·경유 지점·조회 도로 표시. Maps 활성화와 웹 도메인 등록 필요 |
| `OPENAI_API_KEY` | 선택한 경로의 제목·풍경·시간으로 공개 음악 플레이리스트 하나 추천 |
| `TOUR_API_KEY` | 기존 관광정보 조회·AI 코스 생성 API 및 데이터 갱신용. 현재 단일 목적지 경로 비교에는 필요하지 않음 |
| 준비된 `catalog/nationwide.json` | 풍경 길 후보의 장소·좌표·출처. 실행 시 새 관광지를 수집하지 않음 |
| Android 위치 권한 | 출발지에서 **현재 위치 사용**을 고른 경우 최근 GPS 위치 수신 |
| AAOS 차량 상태·차속 권한 | 지원 기기에서 차속·UX 제한 확인. Pleos NaviHelper·차량 카메라 연결 권한을 대신하지 않음 |

## 로컬 API 설정

Node.js 22 이상을 사용하며 추가 npm 패키지 설치는 필요 없다. 프로젝트 루트에서 설정 파일을 준비한다. 기존 `.env`는 덮어쓰지 않는다.

```sh
cd pleos-drive
cp -n .env.example .env
```

사용할 서비스의 키만 서버 `.env`에 설정한다. 아래 값은 자리표시자이며 실제 키를 문서·Android 입력창·웹 입력창·소스에 넣지 않는다.

```dotenv
KAKAO_REST_API_KEY=발급받은_REST_API_키
KAKAO_MAP_JS_KEY=발급받은_JavaScript_키
OPENAI_API_KEY=보유한_OpenAI_API_키
OPENAI_MODEL=gpt-6-luna
PORT=4173
```

기존 관광정보 조회나 카탈로그 갱신을 사용할 때만 `TOUR_API_KEY`를 추가한다. TourAPI는 포털의 Encoding 또는 Decoding 인증키를 지원하며 HTTPS로 요청한다. 서비스 활용 승인·인증·할당량은 실제 요청 결과로 확인해야 한다.

```sh
npm start
```

서버 터미널은 계속 실행해 둔다. 키나 서버 코드를 변경하면 실행 중인 서버를 Ctrl+C로 종료하고 `npm start`로 다시 시작한다. 새 APK 설치만으로 서버 코드는 갱신되지 않는다. 키 없이도 서버 연결 상태는 확인할 수 있지만 목적지 검색·경로 비교·AI 음악 추천은 해당 키가 있어야 한다. 공개 부산역 출발 시연도 경로 비교에는 실행 중인 서버와 Kakao REST 키가 필요하다.

비공개 키와 `.env`는 Git 추적·APK·배포 압축에서 제외한다. 지도 JavaScript 키는 지도 SDK가 사용하는 공개 클라이언트 식별자로 지도 페이지에 전달된다. REST 키나 OpenAI 키를 지도 JavaScript 키 자리에 넣지 않는다.

## Android에서 연결하고 비교하기

1. 차량을 P·0km/h의 정차 상태로 둔다. 차량 상태 미확인으로 화면이 잠기면 **설정 → 차량 · 위치 연결 정보 → 차속 권한 요청**을 확인한다.
2. **설정 → API 서버 연결**에서 `http://10.0.2.2:4173`을 확인하고 **저장 및 확인**을 누른다. 키 설정 표시는 값의 존재만 뜻하며 인증 성공을 보장하지 않는다.
3. **경로** 화면의 목적지를 눌러 장소 이름이나 주소로 검색하고 결과 한 곳을 고른다. 초기 목적지인 해운대해수욕장도 공개 예시이며 변경할 수 있다.
4. 출발지에서 **현재 위치 사용** 또는 **부산역 · 시연 출발지**를 고른다. 현재 위치는 Android 권한과 최근 국내 GPS가 필요하다. 공개 시연 좌표 `35.1151, 129.0414`는 실제 GPS를 바꾸지 않으며 GPS 실패 시 자동 대체되지 않는다.
5. **더 돌아가도 괜찮은 시간**을 0~120분으로 정하고 모든 풍경 또는 바다·해안 / 산·전망 / 숲·나무길 / 강·호수 / 들판·농촌 / 도시 풍경 중 하나를 고른 뒤 **경로 비교**를 누른다. 이 시간은 총여정 예산이 아니라 빠른 길 대비 허용하는 추가 이동 시간이다.
6. 같은 목적지의 빠른 길과, 조건을 충족할 때만 제공되는 풍경 길을 비교한다. 0분이거나 풍경 후보·도로를 확인하지 못하면 빠른 길만 표시하고 이유를 안내한다. 기준 빠른 길 자체를 조회하지 못하면 오류를 표시한다.

풍경 조건 ID는 `all`, `coast`, `mountain`, `forest`, `water`, `countryside`, `city`다. 한강공원처럼 여러 유형에 속하는 후보는 선택 유형을 먼저 표시한다. 장소 제목에서 풍경 단서를 분류한 뒤 실제 도로와 시간 조건을 확인하며, 선택 유형의 후보가 없으면 다른 풍경으로 바꾸지 않고 빠른 길만 표시한다. 계절·일몰·날씨는 이번 분류에 포함하지 않는다.

빠른 길은 Kakao의 시간 우선 옵션으로 조회한다. 풍경 길은 선택한 풍경에 맞는 준비 데이터 후보 한 곳 인근을 통과하고 같은 목적지에 도착하며 자동차 전용도로 회피 옵션을 요청한다. 모든 자동차 전용도로의 제외, 차창 조망, 현장 진입·통행·영업·주차는 보장하지 않는다. 별도 관광지 체류 시간이나 출발지 복귀 시간은 더하지 않는다. 표시 시간·거리는 조회 시점의 공급자 예상값이며 실시간 길 안내가 아니다.

## 서버 주소와 네트워크

개발 컴퓨터 브라우저는 `http://127.0.0.1:4173`, Android 에뮬레이터는 `http://10.0.2.2:4173`을 사용한다. 서버는 `127.0.0.1`에 바인딩하고 에뮬레이터 호스트 별칭을 허용한다. 앱의 `localhost`는 에뮬레이터 자체이므로 기본 주소를 사용한다. 포트를 변경했다면 서버 `PORT`와 앱 주소의 포트를 맞춘다.

앱에는 서버 기본 주소만 저장한다. `/api` 경로·계정 정보·검색어·API 키를 주소에 넣지 않는다. 일반 HTTP는 `10.0.2.2`, `127.0.0.1`, `localhost`에 한정한다. 물리 기기는 에뮬레이터 주소로 연결되지 않으며 별도 배포에는 HTTPS·인증·할당량 구성이 필요하다. 현재 서버는 로컬 개발용이다.

| 상황 | 확인할 내용 |
|---|---|
| 서버에 연결할 수 없음 | 개발 컴퓨터의 `npm start`, 앱 주소, 포트 일치 |
| 키 없음 또는 인증 실패 | 해당 서비스 키 설정, 서버 재시작, 공급자 서비스 권한·할당량 |
| `destinations`·`destination-routes`·`android/music` 404 | APK와 서버를 같은 버전으로 맞추고 기존 Node 서버를 종료한 뒤 다시 실행 |
| 빠른 길만 표시됨 | 추가 시간·풍경 조건과 앱에 표시된 이유 확인. 풍경 길이 항상 존재하는 것은 아님 |
| GPS를 받지 못함 | Android 위치 권한·기기 위치 서비스 확인. 시연하려면 부산역 출발지를 직접 선택 |
| `dapi.kakao.com` 호스트 조회 실패 | Pleos **차량 설정 → 연결 → Wi-Fi → AndroidWifi**가 현재 네트워크인지 확인 |
| 지도 미연결 | JavaScript 키·Kakao Maps 활성화·웹 도메인 등록·네트워크 확인 후 지도 다시 로드 |

## Kakao 배경 지도

Kakao Maps를 활성화하고 웹 도메인 `http://10.0.2.2:4173`을 등록한다. 개발 컴퓨터 브라우저도 사용할 때는 `http://127.0.0.1:4173`을 추가한다. `KAKAO_MAP_JS_KEY` 설정 후 서버를 재시작한다. 키 설정 여부와 실제 지도 표시 성공은 별개다.

앱은 조회한 도로 좌표만 도로 선으로 표시한다. 앱 내부 좌표는 `[latitude, longitude]`, Kakao 요청과 `roads[].vertexes`는 경도·위도 순서이므로 변환한다. 현재 목적지 흐름의 풍경 경유 지점은 한 곳이다. 지도용 현재 위치는 Android에서 지도 페이지로 전달하며 브라우저 geolocation을 사용하지 않는다. 30초보다 오래되거나 미래 시각·잘못된 좌표인 위치는 제외한다. 에뮬레이터 GPS는 개발 컴퓨터의 실제 위치와 다를 수 있다.

WebView는 지정된 Kakao CDN의 HTTP 하위 GET 요청만 HTTPS로 업그레이드한다. 일반 HTTP 허용 범위를 넓히지 않으며 TLS 검증과 리다이렉트·시간·응답 크기 제한을 유지한다. Kakao 출처 표시는 유지하며 지도 자체는 실시간 내비게이션을 제공하지 않는다.

## 안내·빌트인 캠·공유 데모

선택한 경로에서 **안내 시연 시작**을 누르면 실제 주행과 분리된 단계 시연이 진행되고 샘플 장면이 저장된다. **빌트인 캠 촬영**에서는 앱에 포함된 공개 라이선스 풍경 사진을 보고 **경로 미리보기에 추가**로 저장한다. 사진은 공유 경험을 설명하기 위한 예시이며 실제 차량 촬영이나 다른 운전자의 실기록이 아니다. 선택한 도로의 실제 주행 시야를 보여준다고 보장하지 않는다.

기록에는 샘플 사진 식별자·선택 경로·목적지·구간·시각·공유 미리보기 표시 여부가 포함된다. 최대 60건을 기기 안에 보관하며 사진·영상 업로드나 다른 사용자에게 전송하는 기능은 없다. **공유 미리보기에 표시**도 로컬 데모 설정이다. 실제 카메라 접근·영상 녹화·장면 인식 모델·실차 자동 촬영·Pleos NaviHelper는 연결되지 않았다. 사진 출처는 [데모 사진 안내](SCENIC_DEMO_ASSETS.md)를 참고한다.

## AI 음악 추천

정차 중 **음악** 화면을 열면 선택한 경로의 제목·풍경·시간으로 `/api/android/music`에 추천을 요청한다. 선택한 경로가 없으면 일반 드라이브 조건을 사용한다. OpenAI는 등록된 공개 플레이리스트 6개 중 하나의 ID와 추천 이유를 선택하며 제목·제작자·공식 URL은 서버 카탈로그에서 가져온다. 새 목록·곡을 생성하거나 무제한 YouTube 검색을 하는 기능은 아니다.

추천을 받은 뒤 사용자가 **노래 재생**을 눌러야 선택한 목록을 연다. 공식 YouTube Music 앱 → 외부 HTTPS → 내부 공식 웹 화면 순서로 같은 플레이리스트 URL을 시도한다. 자동 재생·전체 곡의 지역별 가용성은 보장하지 않는다. 내부 웹 로그인은 지원하지 않으며 계정 로그인은 외부 공식 앱·브라우저를 이용한다. 앱 백그라운드 전환이나 차량 제한 시 내부 웹 화면을 닫는다.

`OPENAI_MODEL`의 기본값은 `gpt-6-luna`다. 모델 권한·할당량은 요청 결과로 확인한다. 같은 조건의 세션 결과를 재사용하며, 실패를 고정 목록의 AI 추천 성공으로 표시하지 않는다. 후보 출처는 [음악 카탈로그](MUSIC_CATALOG.md)를 참고한다.

## 데이터 전달과 기존 API

목적지 검색에는 검색어만 로컬 서버와 Kakao Local에 전달한다. 경로 비교에는 선택한 출발 좌표와 목적지 정보를 로컬 서버와 Kakao 길찾기에 전달한다. **현재 위치 사용**을 골랐을 때 출발 좌표는 실제 GPS이며, 부산역 시연에서는 공개 좌표다. 현재 경로 비교는 OpenAI에 좌표나 후보를 전송하지 않는다. 음악 AI에는 경로 제목·풍경·시간만 보내며 원본 GPS·개인 영상·청취 기록은 보내지 않는다. 목적지 이름에서 관심 지역은 드러날 수 있다.

조건 변경·취소·앱 백그라운드 전환·차량 제한 후 도착한 과거 요청 결과는 적용하지 않는다. 서버는 Host/Origin을 검사하며 비공개 키와 원문 네트워크 오류를 응답으로 반환하지 않는다. 공개 지도 JavaScript 키만 `/api/map-config`에서 전달한다.

| 경로 | 역할 |
|---|---|
| `GET /api/status` | 서비스 키 설정 여부 확인 |
| `GET /api/map-config` | 지도 페이지용 공개 JavaScript 키와 설정 여부 |
| `GET /api/destinations?q=...` | 현재 Android 목적지 검색 |
| `POST /api/destination-routes` | `{origin, destination, extraMinutes, theme}`로 같은 목적지의 도로 대안 비교 |
| `POST /api/android/music` | `{context:{title,theme,durationMinutes}}`로 공개 플레이리스트 하나 추천 |
| `GET /api/catalog` | 준비된 전국 장소·코스·출처 데이터 |
| `POST /api/android/plan` | 기존·호환 흐름: TourAPI 주변 명소 → AI 방문지 조합 → Kakao 도로·체류 시간 검사. 현재 Android 주 화면은 사용하지 않음 |
| `POST /api/android/recommend` | 기존 준비 코스 후보 재정렬용 호환 API |
| `POST /api/recommend`, `POST /api/route`, `GET /api/places` | 기존 보조 웹·관광정보·코스 조회용 API |

기존 서울시청 공개 출발 코스 생성, 전국 준비 코스 탐색, 보조 웹의 영상 파일·색상 통계 기능은 이전 구현이다. 현재 Android 주 시연이나 실제 차량 카메라 연동 기능으로 안내하지 않는다.

## 개발 참고 자료

현재 앱은 표준 Android Car API로 차속과 `CarUxRestrictions`를 읽는다. 지원하지 않는 일반 Android와 차량 상태를 읽지 못한 AAOS를 구분하고, 차량 UX 제한을 우회하지 않는다. 실제 Pleos SDK 연결은 제공 버전·권한을 확인한 별도 작업이다.

- [Pleos SDK 신청 안내](https://document.pleos.ai/en/docs/pleos-only/create-my-project)
- [NaviHelper 설치](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/NaviHelper/importing-sdk)
- [Pleos 주행 UX](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/driving-restriction-development-guide)
- [Android 외부 앱 실행·패키지 가시성](https://developer.android.com/training/package-visibility/use-cases)
- [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)

실제 GPS·실차·전체 도로 연결성·외부 음악 재생 검증은 이 설정 문서만으로 완료된 것으로 간주하지 않는다. 최신 결과는 [검증 기록](VALIDATION.md)에 기록한다.
