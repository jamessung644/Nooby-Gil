# 목적지 주변 사진 추천과 선택 경유

SCENIC의 기본 흐름은 **목적지 검색 → 주변 풍경 사진 → 사진 한 장 선택 → 그 장소를 경유해 원래 목적지 도착 → Pleos 순정 내비**입니다. 사진 탐색과 경로 변경은 정차 상태에서 사용합니다.

## 화면에서 사용하는 방법

1. **발견 → 목적지 검색 · 풍경 사진 찾기**에서 최종 목적지를 검색하고 선택합니다.
2. 목적지 주변 **5km·10km·20km** 중 범위를 고릅니다. 최초 범위는 10km이며, 좌표와 이용 조건이 확인된 사진을 최대 12개 표시합니다.
3. **OpenAI 이미지 평가**인지 **거리순**인지 확인하고 사진을 고릅니다. 사진을 불러오지 못한 경우에는 사진을 봤다고 처리하지 않고 장소 기준 선택 여부를 별도로 확인합니다.
4. **선택한 사진 경유**의 실제 도로와 추가 시간을 확인합니다. 출발지 설정과 최종 목적지는 그대로 두고 고른 사진의 관광 장소를 경유합니다.
5. 경로를 선택한 뒤 **순정 내비로 안내**를 누릅니다. Pleos는 차량 현재 위치에서 해당 장소를 경유해 최종 목적지까지 다시 탐색합니다.

추가 시간이 부족하거나 장소에 접근하는 도로를 확인하지 못하면 이유를 표시합니다. 사진을 다른 장소로 자동 교체하지 않으며 빠른 길을 사용하려면 사용자가 직접 선택합니다. **사진 없이 빠른 길**은 경유지를 제거하고 추가 시간 0분으로 요청합니다.

## 실제 사진과 AI 평가

사진과 관광 장소 정보는 한국관광공사 **TourAPI KorService2**에서 가져옵니다. `locationBasedList2`의 `firstimage`는 원본 대표이미지, `firstimage2`는 썸네일, `cpyrhtDivCd`는 이용 조건입니다. 현재 구현은 관광지 유형의 사진 중 **`Type1`이 명시된 자료만** 사용합니다. [공식 서비스 명세](https://www.data.go.kr/data/15101578/openapi.do)

서버는 실제 공개 썸네일을 OpenAI Responses API의 `input_image`로 전달합니다. 모델은 사진에 보이는 풍경과 구성을 평가하고 순서·이유·풍경 분류를 반환합니다. 장소명만으로 이미지 평가를 했다고 표시하지 않습니다. OpenAI 키가 없거나 이미지 평가가 실패하면 사진을 거리순으로 표시하고 AI 평가가 적용되지 않았음을 알립니다. TourAPI 조회 실패나 이용 가능한 사진이 없으면 빈 결과의 이유를 표시합니다.

`mapX`는 WGS84 경도, `mapY`는 위도이며 공식 위치 검색 반경은 최대 20km입니다. 이 좌표는 **관광콘텐츠의 장소 위치**입니다. 이미지 정보 명세에는 사진별 촬영 좌표·방향·시각이 없으므로 사진을 찍은 정확한 지점이나 차창 전망으로 해석하지 않습니다. 모델에도 실제 도로 조망·접근성·안전을 추론하지 않도록 요청합니다. [TourAPI 명세](https://www.data.go.kr/data/15101578/openapi.do)

## 사진 선택과 경로의 관계

사진 추천 응답은 원래 목적지와 선택 가능한 관광 장소를 묶은 서명 값을 포함합니다. 경로 서버는 서명을 검증한 뒤 선택된 장소만 경유지로 사용합니다. 다른 목적지의 선택 값, 변경한 값, 만료된 값은 거부하고 사진을 다시 불러오도록 안내합니다. 유효 기간은 30분이며 서버를 재시작해도 기존 값은 만료됩니다.

Kakao로 빠른 길을 먼저 조회한 뒤 **출발지 → 선택 관광 장소 → 원래 목적지** 도로를 조회합니다. 응답 형상에서 관광 장소의 좌표로부터 150m 이내 접근과 허용 추가 시간을 확인합니다. 이는 주차 입구·도보 접근·정확한 촬영 지점 확인이 아닙니다. 사진 경유 경로에는 체류 시간과 출발지 복귀 시간을 포함하지 않습니다.

순정 내비는 확인된 경로의 목적지·경유지 좌표와 이름을 전달받습니다. Kakao의 도로선이나 예상 시간을 전달하는 방식이 아니며, 최종 탐색과 안내는 Pleos가 담당합니다. 결과 확인과 에뮬레이터의 경유지 좌표 반환 한계는 [순정 내비 연결](NATIVE_NAVIGATION.md)을 참고하세요.

## 사진 이용 조건과 외부 전송

공공누리 제1유형은 출처를 표시하면 상업 이용과 변경이 가능합니다. 제3유형은 변경 금지이므로 이번 사진 후보에서 제외합니다. 사진에는 제공기관·이용 유형을 표시하고 원본과 출처를 확인할 수 있게 합니다. 공공데이터 목록의 포괄적인 이용 안내만으로 개별 사진의 이용 조건을 추정하지 않습니다. [공공누리 유형별 조건](https://www.kogl.or.kr/info/license.do), [TourAPI 사진 유형 안내](https://www.data.go.kr/catalog/15101578/openapi.json)

- TourAPI: 목적지 좌표와 검색 반경을 전달합니다.
- OpenAI: 공개 관광 사진의 썸네일 URL, 장소명, 사진 식별자를 이미지 평가에 사용합니다. 개인 영상·사진을 올리는 기능은 아닙니다.
- Kakao: 출발지·선택 장소·최종 목적지의 좌표를 도로 조회에 사용합니다.
- Pleos Navi Service: 사용자가 순정 내비 버튼을 눌렀을 때 목적지·경유지를 전달합니다.

앱은 확인한 공식 사진 호스트 `tong.visitkorea.or.kr`의 `/cms/resource/` 이미지 경로를 HTTPS로 사용합니다. 임의 호스트·인증정보·쿼리·리다이렉트는 허용하지 않습니다. API 비밀키는 서버 환경변수에서만 사용하며 앱에 포함하지 않습니다.

## Gleo AI와의 구분

현재 사진 평가는 **OpenAI**, 사진 검색은 **TourAPI**입니다. Pleos의 Gleo AI 사진 검색·비전 API를 호출했다고 표시하지 않습니다.

현재 공개된 **Gleo Interface**는 Gleo가 앱의 기능을 Android Intent로 호출하고 앱이 결과를 callback으로 돌려주는 음성 연동 방식입니다. 공개 가이드 확인 범위에서 앱이 Gleo에 사진 검색이나 이미지 추론을 요청하는 API 명세는 확인하지 못했습니다. 향후 “목적지 주변 사진 추천 화면 열기”를 SCENIC 기능으로 등록하는 방향은 검토할 수 있지만, 이번 수정본에는 Gleo 음성 연동을 추가하지 않았습니다. [Gleo Interface](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/core-concepts)

실제 연동에는 `assets/schema.json`, 기능별 Intent 처리와 스키마 검토·승인이 필요합니다. 현재 가이드는 최대 3개 기능과 7초 callback 제한을 명시하므로 긴 사진 조회를 Gleo의 완료 응답과 동일하게 취급하면 안 됩니다. [App Schema](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/app-capability), [스키마 전달](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/deliver-schema), [callback 규칙](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/action_callback)
